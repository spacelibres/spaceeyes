# 科学计算与服务器任务验证

## 算例记录

每个算例保存：依赖版本及 features、数据版本与校验值、覆盖区间、参考系和单位、时间尺度、初始状态、力模型、积分方法与容差、输出采样、参考结果来源、误差度量及通过阈值。阈值由任务精度确定，测试前声明，不在结果失败后放宽。

## 按能力选用的检查

| 能力 | 验证重点 |
|---|---|
| 无摄动两体传播 | 与解析或可信参考解比较；检查适用条件下的能量与角动量误差 |
| 摄动、推力和机动 | 与相同假设的参考结果比较；检查步长/容差收敛与事件边界；受力系统不要求机械能恒定 |
| 燃耗 | 核对质量状态、推力和比冲等输入，验证质量变化；不默认机动 API 已自动处理 |
| 时间与参考系 | 往返转换、时间尺度、轴向约定、边界历元；测试缺失数据和覆盖外错误 |
| 输出与显示 | 科学状态与显示状态分开比较；改变帧率、播放速度不应改变同一配置的科学结果 |
| 大模型或 TS 插件输入 | 权限、对象归属、数值范围、单位/参考系/历元缺失、无效资源与失败反馈 |

不同程序结果一致不等于独立验证：注明参考数据和算法来源，避免同一实现互相证明。数值比较采用任务规定的容差，不擅自要求跨平台逐位一致。

## 服务器任务检查顺序

1. 固定服务器依赖、features、输入数据及计算配置，验证最小科学算例。
2. 验证提交、校验失败、排队、运行、完成、失败与取消的任务行为；状态必须可查询，不能将取消请求等同于已经停止。
3. 核对任务与用户/插件归属；页面断开后能按权限重新查询，结果标明来源与有效范围。
4. 客户端获取结果并转换到 Bevy 显示坐标；以同一时刻和参考系验证数值，不要求客户端加载 Nyx 或执行积分。
5. 检查重复提交策略、超时、资源限制与清理；重试不能默默创建重复高成本任务。具体策略在后续任务设计中确认。

上述为后续 Nyx 接入的专项检查，不进入 NASA Eyes 第一版显示验收，不替代 AGENTS.md 的完整提交检查。没有服务器与科学算例证据，不能将技能书安装报告成 Nyx 已集成。Nyx 不要求构建浏览器 WASM。
