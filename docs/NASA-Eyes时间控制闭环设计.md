# NASA Eyes 时间控制闭环设计

依据全局对齐路线第三批。参考用户提供恢复源 solarsystem/eyes/src/ui/components/TimeControls.js，核对22个倍率锚点及101档分段映射。滑块表示播放速率而非日期；日期输入承担跳时。反向50档，正向含1x共51档，按最大时间单位取整，保留重复倍率；按钮跳过重复倍率。

独立提供倍率1x、当前时间、LIVE状态和可折叠时间栏。1x仅改变速率，当前时间执行显式跳时，LIVE要求播放中、倍率严格1且与墙钟绝对差严格小于1000毫秒；历史时间以1x播放不自动标为LIVE。暂停保留可恢复倍率。

Bevy核心继续作为唯一科学时钟，宿主纯函数不建立时钟，不累加时间；UTC显示与TDB传播通过既有转换边界。时间操作沿现有受控SDK执行。折叠栏不改变时间、倍率或播放状态。

数据覆盖不足、加载或求值失败明确反馈；不以当前墙钟替代科学时刻，不外推伪造覆盖数据，不以无效状态展示LIVE。验收覆盖正倒播、暂停恢复、倍率1、当前时间、折叠恢复、严格LIVE边界及覆盖错误。

NASA非零倍率滑动、加减档和1×按钮都会恢复播放；暂停只由独立播放按钮控制，保留暂停前倍率。
