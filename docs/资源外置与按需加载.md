# 资源外置与按需加载

依据用户 2026-10-30 确认的边界，WASM 承载核心程序；模型、纹理、字体、音频、星历及场景资源独立存放在服务器，不编译成程序载荷。保留现有 Bevy/TS SDK 分工，不自建三维引擎。

| 触发 | 允许的资源请求 | 未触发时 |
|---|---|---|
| 打开总览 | 总览位置和轨迹需要的轨道 DYN | 不下载高清表面和环 |
| 选择天体 | 该对象姿态 DYN、六面表面；土星同时需要上下环 | 其他未选择天体保持基础几何 |
| 标签实际出现 | 同源固定字体 | 不提前加载字体 |
| 选择含模型的场景 | 受控模型及其依赖 | 不预取模型目录 |
| 后续音频、专题等功能 | 仅对应已触发的资源 | 默认不加载 |

注册目录只提供资源描述，不等于下载。重复选择不重建已绑定表示，已触发资源可复用；错误保留失败反馈，不能把基础几何报告为真实表面已加载。退出释放会话及渲染资源，取消按现有生命周期处理；浏览器 HTTP 缓存不在退出时强制清空。

字体使用 Bevy 0.19.1 原样 FiraMono-subset.ttf，18848 字节，SHA256 `45131c5e913a5c7b4311101303e3c320a97b93a27a64b7262b533ee0d31ae03c`，通过服务器 `/assets/fonts/FiraMono-subset.ttf` 加载。许可证见 THIRD_PARTY_NOTICES.md。构建准备拒绝仍包含这一完整字体载荷的 WASM。字体暂不覆盖完整中文。

运行时生成的基础网格、着色器和程序常量属于渲染算法，不作为业务资源抽离。已核对当前浏览器 feature 图：SMAA、tonemapping、DFG、面光源及蓝噪声的内嵌图像功能未启用。本次移除 default_font；不修改上游 Bevy 源码，也不将 WASM data section 全部视为图片。

本批解决资源边界和触发时机，不代表 debug 构建体积已经完成发布优化。符号剥离、发布优化和传输压缩应单独测量，不以字体外置减少的 18 KB 冒充百 MB 级代码体积优化。
