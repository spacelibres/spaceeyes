# 太空之眼平台架构书

状态：方向已确认，详细设计待逐项讨论。

## 平台是什么

太空之眼（SpaceEyes）是一个可通过插件扩展的三维仿真平台。范围覆盖天文学、各类天体和空间场景，不局限于地球及人造卫星。

## 两个核心概念

1. 平台核心提供通用三维仿真基础与统一接口。
2. 插件通过公开接口增添具体功能，始终围绕平台开展。

## 已确定的技术方向

- 采用 Bevy 作为三维基础引擎，Rust 核心编译为 WASM，在浏览器中运行。
- 三维渲染、模型、材质、灯光、动画等能力优先复用 Bevy 及现有库，不自行重写通用三维基础。
- 网页宿主采用 TypeScript + Next.js；插件使用 TypeScript，插件页面与界面沿用该技术体系。具体打包和加载方式待设计。
- 通过插件市场管理和分发插件。Bevy 内部的 Rust 插件机制不等同于平台的 TypeScript 插件市场。
- 平台提供统一 SDK。插件通过 SDK 使用核心能力，不直接依赖 Bevy 内部结构。
- SDK 配套技能书，明确可用接口、权限、禁止行为及验证要求。
- 接入的大模型可以按技能书编写插件；其产物遵守与人工插件相同的接口、权限和验证规则。边界由运行时约束与验证落实，不能仅依赖提示词。

## 核心与插件的边界

核心负责通用三维基础、运行管理及受控能力接口。具体领域功能通过插件扩展；不预先规定所有科学算法必须进入核心，也不把插件局限为界面。

核心与插件的详细职责、数据协议和权限清单，逐项讨论后确定。旧实现中的模块划分、接口和术语不自动成为新架构约束。

## 下一步

先明确核心和插件各自的最小职责，再验证 Bevy 的浏览器集成、基础三维能力及天文尺度显示。验证通过后逐步制定 SDK、技能书和插件市场方案。
