# C0核心接口、依赖与验收详细设计

版本：0.0.0｜状态：设计完成、待审定｜日期：2026-10-27

## 1. Rust crate依赖图（拟定）
foundation：纯值类型、标识、错误。
time → foundation。
spatial → foundation。
resources → foundation。
scene → foundation。
simulation → foundation + time + spatial + scene + resources的公开只读接口。
rendering → foundation + resources + frame-snapshot只读类型。
engine → time + spatial + resources + scene + simulation + rendering。
protocol-adapter → engine facade + generated-proto。
wasm/native → engine + protocol-adapter + 平台设备适配。

为避免环，FrameSnapshot的只读值类型定义在foundation或单独无依赖snapshot-types，不在simulation或rendering中定义。Scene保存FrameId值而不依赖Spatial可变图。依赖图是设计，不是已运行的cargo metadata。

## 2. 公共接口清单（候选）
Engine: submit_command, query, advance, latest_frame_snapshot, shutdown。
Scene: validate_scene_command, apply_transaction, snapshot。
Spatial: register_frame, resolve_transform, graph_revision。
Time: apply_time_command, advance_elapsed, snapshot。
Simulation: enqueue_task, cancel_task, poll_ready, validate_result。
Rendering: render_frame, pick, device_status。
Resources: request_resource, lease, release, resource_status。
ProtocolAdapter: decode_request, validate_envelope, encode_response, encode_event。

所有外部写命令只进入Engine。Simulation不能直接持有Scene可变引用。Rendering只能读取FrameSnapshot。

## 3. 快照提交时序
1. Host校验能力并提交Proto Command。
2. ProtocolAdapter校验版本、字段、权限上下文。
3. Engine为请求分配顺序并校验预期修订。
4. Time产生TimeSnapshot；Simulation只执行针对该时刻的任务。
5. ResultValidator核验generation、requested_instant、coverage、对象句柄、参考系修订、来源。
6. Scene事务提交；失败不发布半完成快照。
7. Engine原子发布FrameSnapshot(session_id、instant、generation、scene_revision、frame_revision、resource_epoch、frame_sequence、availability)。
8. Rendering只读最新完整快照；旧帧如继续显示须标注stale。

## 4. Proto关键字段设计
公开ID建议使用有命名空间的不透明string；内部slot+generation不序列化。
TimeInstant采用time_scale、epoch_id、seconds(int64)、nanos(uint32)；nanos取0..999999999。科学坐标位置m、速度m/s、角度rad、角速度rad/s。
CommandEnvelope: request_id、session_id、expected_revision、payload(oneof)。
TaskResult: task_id、generation、requested_instant、coverage、provider_version、payload(oneof)。
FrameSnapshot: session_id、instant、generation、scene_revision、frame_graph_revision、resource_epoch、frame_sequence、availability。
这些是字段语义候选，字段编号与TT/TDB规范尚未冻结。

## 5. 设计验收追踪
C0-T01 Scene单命令与批量事务原子性。
C0-T02 Seek后旧任务不覆盖当前场景。
C0-T03 连续播放同generation但时间不匹配的结果拒收。
C0-T04 Frame撤销后关联对象不隐式删除。
C0-T05 共享纹理与租约释放。
C0-T06 GPU设备丢失不破坏Scene科学状态。
C0-T07 Rust/TS Proto时间与ID往返。
C0-T08 WASM/Native相同公开消息语义。
C0-T09 渲染只消费一致FrameSnapshot。
C0-T10 插件越权命令被拒绝。
C0-T11 crate DAG无环。
C0-T12 NASA Eyes太阳系模拟数据端到端显示。
