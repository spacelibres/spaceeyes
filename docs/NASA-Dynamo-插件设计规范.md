# NASA Dynamo 数据源插件设计规范

版本：0.0.1｜状态：规划草案｜日期：2026-10-27

## 1. 已确定的架构决策

NASA Eyes DYN 数据解析**以独立插件形式存在**，建议插件标识 `spaceeyes.nasa.dynamo`。Rust Core不包含DYN文件解析、NASA地址、NASA数据目录或专有轨道插值算法。首期采用TypeScript插件以复用已验证的参考实现；不得为追求语言统一而将其硬塞入Rust核心。未来可在保持公开契约的前提下替换插件内部计算实现。

## 2. 插件职责与模块

- `NasaDynamoProvider`：通过受控网络代理/授权域名获取在线DYN，不直接将远程源当作稳定公共API。
- `DynamoParser`：读取小端v1/v2、orb/pos/lin/ori/quat、内联与分段数据，保留原始记录索引。
- `DynamoSegmentManager`：按仿真时间选择有效分段，处理重复时间边界和缺口。
- `EphemerisEvaluator`：计算位置、速度、姿态及角速度，显式区分不可用、越界、非法样本。
- `DynamoCache`：按路径、数据版本与实际覆盖区间缓存，支持失效、取消和资源配额。
- `DynamoDataAdapter`：将查询结果映射到统一的SpaceEyes Proto消息。
- `DynamoPlugin`：注册能力、响应SDK查询、处理启停和释放资源。

## 3. 接口与数据边界

外部原始DYN属于插件内部数据格式，不要求全部转换为Proto文件。插件与宿主/核心之间的**公开结构化交换**使用版本化Protobuf。核心只接收标准化的对象身份、时间、参考系、位置/速度、姿态/角速度、来源、有效范围与错误状态；内部热路径不强制逐次序列化。正式Proto字段、时间零点和参考系命名仍需另行审定。

## 4. 源码与科学验证

参考来源：`spacelibres/solarsystem/src/lib/dynamo`、`src/solar/domain/ephemeris.ts`、`src/solar/runtime/explorer-runtime.ts` 及其测试。不得只复用简化的最近历元orb位置算法而遗漏完整求值器。五种记录、重复/冲突时间、索引窗口、分段切换、取消/超时、参考系及四元数WXYZ顺序必须建立黄金样本测试。既有历史测试不等于本插件已通过验收。

来源核验已完成：固定提交`4a8a83be2ff8298d7fe26fc5c9bbfe47f2fee7db`，逐文件摘要、自研TS与恢复源码/NASA数据的边界、五类合成样本设计见[P04参考DYN来源核验与黄金样本规范](P04参考DYN来源核验与黄金样本规范.md)。自研TS可按包级MIT复用并署名；`eyes/`恢复源码与NASA夹具不得复制。真实样本入库仍待再分发许可确认。

## 5. 安全与权限

声明NASA数据域名、缓存范围、请求预算；通过宿主权限代理访问网络。插件不得直接操作Rust核心私有状态、安装服务端代码或扩大自身权限。数据来源、缓存与再分发许可逐项核实，未经确认不将原始NASA资源打包公开分发。

## 6. AI技能书与最终目标

该插件必须配套版本化`SKILL.md`，记录API、单位、时间、参考系、能力范围、示例、错误、权限及可执行验收。未来AI按技能书查询星历、组合场景插件，而非重新解析DYN；AI自主生成插件仍需受控构建、测试、授权安装与回滚。

## 7. 首期验收

能在合法可访问的NASA数据源上按需加载地球、月球、木星系统的适用DYN；在指定时刻通过公开SDK返回可验证的星历状态；分段切换和异常数据不产生伪造状态；停用插件后网络任务、订阅及缓存句柄按策略清理。具体设备、时间与数值容差待审定。

## 8. 状态

本文件仅定义插件设计，尚未作为受限插件安装到宿主沙箱。统一开发版本保持0.0.1；早期0.0.0记录已被项目版本治理覆盖。2026-10-27已完成参考仓库固定提交、逐文件许可与格式证据核验，以及五类合成样本规范；解析、求值、分段加载与有界缓存已实现于`packages/nasa-dynamo`（24项合成测试），受信浏览器宿主的`?scene=solar`已通过只读代理显示四个天体。权限沙箱P03、时间/参考系ADR与真实科学样本仍未完成。
