# 太阳特效实时调参面板设计

状态：已实施并通过集中检查及GPU交互验收；按用户要求将现有太阳风、等离子体和日珥可调量集中到界面。

## 入口与操作

太阳对象信息面板增加“太阳特效调试”，五个折叠组；保持现有spacelibre标志与配色，不遮挡主画布。滑块配数字输入、单位、有效范围、默认值；拖动实时预览，连续更新合并到每帧一次。提供各组恢复默认、全部恢复默认、关闭特效、暂停特效动画、导出/导入JSON和本机保存。离开工作区取消在途更新；重新进入可恢复上次确认配置。错误保留最后有效参数并显示原因。

推荐直接在既有对象面板实现；单独全屏调试页不便边看边调，任意WGSL编辑器会越过SDK边界。本设计不加入任意shader执行。

## 数据与架构

UI -> WorkspaceRuntime -> 已批准数据插件会话 -> 受控SDK -> Rust双重校验 -> 材质uniform/有界几何。扩展既有stellar结构为具名配置；旧coronaIntensity/flowSpeed调用保持默认兼容。公开字段统一元数据定义用于控件和默认值，Rust独立校验；不开放Bevy World、任意路径和WGSL源码。

调参必须有独立更新入口，避免现有visual.set每次增加资源修订导致整球、贴图重建。参数更新保持对象所有权和scene.visual能力要求，不改变DYN科学位置/半径。颜色和强度变更只更新已有资产；关闭开关或离开距离区间释放专用资源。

Parker温度/参考密度变更在TS计算单元重新生成64点有界查表，通过受控SDK提交，Rust检查单调半径、有限非负密度和递增飞行时间。不能只改说明文字或只改一份静态JSON。NASA参考半径与公式采用的名义半径差异须明确显示，不偷偷更改科学对象。此计算是现有Parker显示模型，不接入Nyx，也不声明完整MHD。

当前日珥为程序网格加WGSL动画，外流为体积积分，尚无离散粒子模拟；面板使用实际名称，不能用“粒子数量”假装存在粒子系统。未来真实粒子实现另行规划。

## 验收

1. TS和Rust对未知字段、越界、NaN、配对约束和归属权限均拒绝；旧接口兼容。
2. WASM集成验证参数能到达核心，更新不重建对象资源；释放后调用失效。
3. 真实浏览器逐组抽测强度归零、暂停/恢复、颜色变化、尺寸变化、LOD退出、重置、持久化、导入导出；不接受只做静态控件。
4. 可见窗口近景和总览测GPU负载，保留画布尺寸、设备和采样方式。不要把截图成功当成帧率达标。
5. 完整集中检查、CHANGELOG、补丁版本、提交推送和gh检查CI，冻结分支不改动。
