# 太阳等离子体动画修正

用户已确认以动态等离子体WGSL替换光晕和铁丝日珥。

根因：旧光晕使用球面法线与观察方向推导屏幕径向距离，在透视近景产生错误中心和放射伪影；日珥是固定细管上的周期亮度变化。

实施：外壳以真实球心及半径构造观察射线，24步有界体积积分，三维连续噪声控制向外输运、局部伸展和热度衰减；无经纬UV极点汇聚。日珥增宽为多股弧束，以多尺度非周期噪声、沿弧输运、边缘衰减和独立生灭调制密度，保留真实遮挡。视觉动画使用渲染时间；科学TDB时间、DYN和半径不变，flowSpeed=0停止动画。

验收：完整集中检查；实际GPU太阳近景、旋转和连续时间截图，检查着色器ERROR；不将程序噪声宣称为磁流体动力学或实测太阳。

## 0.0.23 修正

用户要求太阳不接受外部照明、等离子体更广泛自由飘散。stellar球面统一使用unlit材质，保留NASA纹理但不参与PBR漫反射/高光/阴影。普通行星继续受光。体积边界扩到2.8倍科学半径，32步固定预算，根部火舌与外向稀薄团块分别建模；边缘衰减至透明，不画固定外壳。该范围是视觉参数，不是太阳风物理传播范围。科学半径不改。

## 0.0.25 前后遮挡修正

用户反馈等离子体似乎只从球体背后发出。根因是体积代理背面位置参与深度比较，导致太阳表面前的有效积分也整块被拒绝。片元改为显式输出射线体积入口深度；相机位于体积内时取reverse-Z近端。积分在首次命中太阳单位球面时截断，保留前景等离子体且遮住背面。外部不透明物体位于体积入口之前时继续受深度测试遮挡；尚未做所有位于体积内部物体的逐采样场景深度截断，不能宣称通用多物体体积遮挡全部验收。

## 0.0.26 三维外流空间层次

用户要求正面等离子体向摄像机靠近的立体感。旧模型外壳2.8R通常在摄像机前止步，方向噪声的时间坐标偏移及纯加法叠加又削弱深度。修正为1..12R内的三维笛卡尔拉格朗日密度标签 q=normalize(p)*(1+11*fract((tau(r)-t)/tau(12R)))，沿Parker特征线输运，不使用摄像机方向造假；周期边界淡入淡出，扰动仅为显示。64点对数半径物理查表，常数时间索引，48步前后积分。前到后预乘发射/显示消光替代纯加法，近景相机可处在外流中，透视自然产生靠近放大和视差。

消光与密度增强仍是可视化映射，不是经CHIANTI标定的光谱传输；远处真实太阳风不等同可见浓烟。12R是当前显示包围体，数值Parker表仍到1AU。没有MHD磁场求解，也未将静态光球改成真实对流。

GPU近景首次截图超时，未见shader报错；优化噪声哈希去除sin，并仅在近表面计算火舌，减少全屏体积内的重复多层噪声开销。实际性能仍以回归为准，不声明头显帧率。

## 0.0.27 视觉强度收敛

用户反馈外流过于夸张。只调整显示映射：外流增益4.0→0.55、发射相对量幂0.25→0.30、团块阈值0.48/0.72→0.53/0.77、冷端红光0.7→0.35、根部火舌权重0.75。保留三维空间和径向输运，不改变Parker物理参数或数据。外流应稀薄、局部可见，背景星空保持清晰。


### 按距离创建与回收

核心0.0.21以相机到恒星中心的距离除以当前恒星渲染半径进行LOD判断，不受科学单位到显示单位变换影响。进入阈值8R，退出阈值10R，6..10R线性渐隐，滞回避免边界反复创建。远处仅保留轻量声明，不生成日珥网格和专用材质，不提交等离子体绘制；离开或移除源天体回收专用资产。共享球网格和Bevy材质插件的着色器/管线缓存保留供复用；当前不承诺远景完全没有WGSL网络请求。
