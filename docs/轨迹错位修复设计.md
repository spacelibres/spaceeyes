# 轨迹错位修复设计

依据平台架构书及用户对轨道偏离天体、折角的反馈。日期：2026-10-30。

## 已复现的原因

旧宿主仅在配置时对一周期范围采样 128 点，时刻未随轨迹提交，当前天体位置不一定是其中任何顶点。近景下折线弦与真实曲线的误差远大于天体半径；统一时钟继续播放后，旧轨迹也没有当前时刻的连接语义。水星真实 DYN 在 TDB 846615186.622 秒，旧折线最近距离约 22451.318 公里，水星半径 2439.4 公里。

## 本批修复与边界

- TS 数据源按真实 DYN 求值产生带时刻的采样；一般对象最多 256 点，观察目标最多 2048 点，兼顾全轨迹均匀采样与当前位置附近的指数密集采样，明确包含当前时刻。没有强行圆化或首尾闭合。
- SDK 轨迹接口兼容旧静态调用，第三参数可提供严格递增的 TDB 顶点时刻；Rust 独立校验长度、有限性、顺序、归属及原有每会话 4096 顶点预算。清空/移除/停用清理元数据。
- Bevy 在对应时间区间插入核心当前对象位置，使用与天体相同的显示原点、单位和轴向；正向、反向播放与恰好在顶点时都保持一致。仅在已提供时段内连接，不向覆盖外延伸。
- 详细采样窗口过期时从已加载数据重新采样，刷新检查最多每 100 毫秒一次，不逐帧下载数据；更换目标时先缩减旧目标采样再增加新目标，防止预算瞬时超限。
- 本批修复折线表示及时间连接，不改变 DYN 求值算法，不宣称科学精度已认证。真实轨道可为椭圆，透视可使其扁平；行星近景中远处轨迹局部接近直线也可以是正确投影，不承诺每个视角都显示圆。

## 同批补充：太阳居中与土星环

按用户后续反馈，总览显示原点固定为当前日心宿主的科学原点，范围按天体到原点的最远距离计算，不再用不对称的行星包围盒中心。初始化、环绕和返回总览时相机看向此原点；不改动行星科学坐标，后续其他中心体系另行显式配置。

土星环沿用固定资源及 Bevy PBR。本地底面 PNG 是 L 灰度图，不能把解码后的全不透明 alpha 当作环缝。实际复验中普通平面漫透射依然过暗，最终按用户要求让正反面共用上表面颜色/alpha，以 Bevy ExtendedMaterial 对环采用光线与视线半向量的粒子受光近似，仍使用引擎方向光、PBR 和透明度，不设 emissive/unlit。受控外置程序 `web/resources/shaders/ring-particles.wgsl` 由准备脚本发布，不开放任意插件 shader。此近似不是标定的环粒子散射或 NASA 全部阴影复刻。

补测试不对称行星布局下的中心/视角切换，以及灰度底面保持正面透明环缝。GPU 检查初始化总览太阳中心，土星正背面可见和透光，不用编译通过代替画面验证。

## 同批补充：统一 AU、渐隐和父体轨道

采样数据核对见 units.json：DYN 半长轴数值与千米一致，地球约 1 AU、海王星约 30.28 AU。总览显式使用 149597870.7 km/AU（NASA/JPL Astrodynamic Parameters 引 IAU 2012 B1），不逐个压缩轨道；局部比例仅用于浮动原点精度，同一场景的所有对象与轨迹使用相同比例。

带时间轨迹增加受控 originId 与 colorRgba：月球轨道由原始地月相对记录采样，并跟随地球当前位置；世界科学状态仍包含地球位置与月球相对位置，不改科学求值。宿主按对象颜色设置线条。局部观察 16 个参考半径以内轨迹隐藏，在 16—128 个参考半径之间平滑恢复，覆盖带环天体的初始完整取景；不是通过渲染日心历史月球轨迹冒充地月轨道。

解除 1000 倍参考半径的拉远上限并扩展裁剪距离；拉远至太阳系范围时核心自动解除局部焦点，宿主同步回到总览，太阳回到中心。具体像素、手势节奏及完整 NASA 相机对照继续单独记录。

## 最终集中验证

固定同一水星时刻对照旧折线距离与新采样顶点距离；测试时间连接、端点不伪闭合、元数据校验/清理、SDK 复制、晚序目录目标切换后的真实 WASM 预算。最终执行全量集中检查，实际浏览器观察水星近景、播放/暂停及反向时间；记录实际截图及尚未完成项后提交推送、gh 跟踪 CI。
