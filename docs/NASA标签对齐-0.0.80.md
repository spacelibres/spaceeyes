# NASA 标签规则实施（0.0.80）

用户确认按上一轮源码分析实施，替代0.0.79“重叠不隐藏”临时规则。

1. screen_layout负责固定投影锚点、像素取整、空间索引、权重/距离/名称决胜；持久保存遮挡状态，每帧最多轮转20项，禁止重新分配标签位置。空间索引用规则网格实现等价矩形查询，不移植NASA四叉树代码。
2. 名称保留实体和字形度量，通过透明度过渡；显示0.25秒、隐藏0.75秒，ease-out；普通名称0.35、行星与太阳0.75、悬停1。碰撞隐藏只作用名称，不删除天体模型、轨道或独立点标记。
3. 点击资格与视觉透明度分离，0.35普通名称仍可点击；碰撞判为隐藏即停止名称命中，天体本身仍可点击。离屏/实体遮挡/用户先前确认的选中近距规则独立保留。
4. 编写密集重叠、稳定决胜、20项轮转、公平轮转、像素定位、渐变与删除清理回归；先红后绿。集中跑全项目检查和浏览器密集卫星/悬停场景，独立审查，版本、CHANGELOG及提交推送。

本批不更改科学位置、相机、轨迹、资源加载及帧预算。NASA近距VisibleInterval归一化半径与当前平台兼容规则仍需单独逐场景验收，不能将标签整批工作宣称全引擎像素等同。

## 源码核对与实现边界

对照 LabelQuadtree.update 的20项轮转、_isLessWeightsAndZ 的权重/距离/名称顺序；DivComponent 的固定锚点和偶数视口四舍五入、奇数视口向下取整；app.css 的0.35/0.75/1透明度与0.25/0.75秒ease-out。源码哈希保存在evidence/labels-0.0.80/nasa-source.json。

网格仅用于标签矩形查询；不改变天体几何、科学半径、轨迹范围或加载清单。新标签第一次登记全部建立索引，后续每帧只更新最多20个缓存矩形和重叠状态；文本投影位置仍逐帧跟随天体。隐藏名称保留Bevy实体与字体度量，退出目录或失效时清理索引。

独立审查发现长帧0.1秒截断/零时间步虚构会破坏时长；已新增先失败后修复回归，渐变按有限非负实际时间推进。星体选中/近距与实体遮挡兼容规则独立保留，不把本批称为NASA全部显示行为像素等同。
