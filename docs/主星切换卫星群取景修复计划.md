# 主星切换卫星群取景修复

用户确认问题是切换主星后看不到卫星群，而非某颗模型加载失败。实测木卫二模型ready，火星/木星/土星/天王星/海王星主要卫星真实DYN均ready，保留证据；不能将此误报成NASA源服务故障。

根因：select无条件设nearby并最终focus，主星本体占满视野，主要卫星多数处于视野外；优先加载只包含选中对象和依赖，系统取景所需卫星尚在后台；后台完成不更新顶部计数。

沿用户本轮“切换主星要看到卫星群”的要求：开启天然卫星时，选中有主要卫星的行星默认system，将主要卫星纳入首批数据；拟合使用当前ready成员，失败不伪造对象；其它航天器仍后台，少数主要卫星数据等待不等于加载全部目录。聚焦按钮仍nearby，单颗卫星/航天器选择仍nearby，关天然卫星不自动family。保持现有Minor Moon目录选择和按需边界，本批不宣称292颗土卫都自动加载，也不扩展缓存/相机预算。更新后台加载计数。

使用宿主集成测试先验证五个外部主星选中后mode/system/members正确、聚焦恢复nearby、无卫星水星仍nearby；保留场景切换、分享恢复、旧请求取消、队列与480倍率测试。完整check-core、独立审查、实际WASM五系统及卫星/聚焦往返、真实数据/模型日志检查后，web补丁递增并提交推送当前分支。
