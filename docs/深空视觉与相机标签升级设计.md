# 深空视觉、相机惯性与标签升级设计

日期：2026-10-30。状态：用户已确认，按本设计实施；验证证据见 evidence/deep-space-0.0.21。依据平台架构书、第一版 NASA Eyes 基线与用户本轮三项要求；当前分支 codex/bevy-planning，冻结分支不动。

## 本轮整体结果

一次交付相机操作、深空视觉与标签三个相互关联的模块，再集中测试。保持现有真实 DYN、父体关系、统一科学时间、受控插件、资源外置及所有已交付功能。使用 Bevy 内置渲染、后处理与通用显示能力，不引入第二套三维引擎。

## 1. 轻量惯性

当前 orbit_input 直接改变 yaw/pitch/distance，没有松手后的速度衰减。改为时间步长无关的阻尼运动：鼠标输入立即响应，释放后短暂自然收敛，反向输入立即制动。

- 旋转初始阻尼半衰期约 60～80 ms，正常释放后约 0.25～0.35 s 收敛；残余速度和角位移有上限，避免一直漂移。最终参数按实际鼠标操作校准。
- 缩放在对数距离上平滑，保留现有连续近景—太阳系缩放范围及自动返回总览语义，不重新引入近景硬停。
- 时间步长、掉帧与窗口失焦有明确限制；切换目标、视角预设、返回总览、退出与重入清除旧速度。聚焦过渡和输入惯性分开，避免两套插值重复拖慢响应。
- 将来 VR 头部姿态直接跟踪，不施加鼠标式惯性。本轮实现鼠标相机，保留输入策略边界。

## 2. 银河、星光与太阳

推荐“真实银河背景 + 已有三维恒星点 + 局部发光效果”分层组合。只贴一张含全部亮星的图会与现有星点重复；完整体积银河/全场景光追超出本轮 WASM 与 VR 预留预算。

### 银河资源

NASA Eyes 原资源由 SkyboxComponent 球面映射 `env_maps/starmap_2048.jpg`；已定位原定义与映射。另已核对 NASA 官方 Deep Star Maps 2020，提供 **milkyway_2020_4k.exr**：赤道 ICRF/J2000 全景、4096×2048、线性 HDR，并专门移除了前景亮星，更适合叠加现有 42667 个恒星点。

优先采用该银河背景独立版本，经成熟 EXR 解码工具在服务器转换为受控显示贴图，保留原始来源、尺寸、哈希和曝光/色彩转换记录；浏览器不下载 EXR 工作原件。4K 为本轮基础质量，接口保留更高分辨率资产等级，未加载等级不提前下载。

实际资源已下载核查：NASA SVS 全景 36436668 字节、EXR dataWindow 为 4096×2048；NASA Eyes sun_glow.png 为 1771 字节。原 Eyes starmap_2048.jpg 当前返回 403，不能宣称可用，因此采用已核验的官方银河原件。证据与哈希见 `evidence/deep-space-design/resource-audit.json`。

全景按赤经/赤纬方向映射，核对左右、接缝、极点及银河中心，不以任意旋转凑视觉。银河位于无限远方向背景，恒星点继续保留源空间方向、距离与星等，太阳/行星处于真实三维场景。前后遮挡及透明环绘制顺序延续现有验证。

### 发光层次

- 恒星保持稳定发光，光晕按星等、颜色和屏幕像素尺度控制；保留点核心与外围柔和光晕，避免白色方块和整屏泛白。
- 优先复用 Bevy HDR/Bloom 等成熟后处理；光晕强度和分辨率有预算，UI 文本不参与泛光。星等相对关系继续可追溯。
- 太阳使用现有真实表面贴图，加受控自发光、日冕及缓慢流动的等离子体视觉；按观察距离降低远景开销。日冕流动是视觉模拟，不表述为实时太阳活动观测。
- 显示效果经受控 SDK 声明，插件不获得任意 shader、Bevy World 或相机内部结构；贴图、着色器和必要噪声资源继续外置，不嵌入 WASM。

### VR 预留

银河、恒星、太阳特效遵循每个视图的投影和眼位，不用固定屏幕覆盖制造假视差。无限远银河保持远景方向，有限三维目标自然产生空间层次。保留后续双眼渲染与质量档位，不宣称本轮已经实现 WebXR、头显接入或立体性能验收。

## 3. 标签碰撞、遮挡与距离变化

现有文字只做固定估算框避让并尝试七个偏移，没有完整的天体遮挡和距离渐隐。升级为统一标签可见性策略，绘制与拾取使用同一结果。

- 使用实际字体度量/布局边界和安全间距判断标签碰撞。空间不足时按优先级隐藏，不靠大幅搬移把标签堆到其它天体旁。
- 检查相机前后、视口和前景天体遮挡；被球体遮住的标签与远景标记一起隐藏，不能从行星内部透出来。
- 随取景范围、目标屏幕占比和拥挤程度渐隐/恢复；太阳系总览保留可分辨的主要行星，进入单一天体近景后收起无关远处标签。主体占据大部分屏幕时，自身中心标签也淡出，名称仍在对象信息区可见。
- 选中目标在符合可见条件时优先；加入滞回和短渐变，抑制缩放边界的闪烁。保留用户图层总开关。
- 隐藏或透明度低于可交互阈值的标签不参与点击命中；天体本体的三维拾取保持独立。

## 验收与交付

1. 确定性测试惯性衰减、帧率差异、反向制动、速度限幅与所有重置路径；实际鼠标验证连续缩放和松手手感。
2. 核对银河源哈希、解析/转换、映射方向、曝光和请求清单；银河与七层星点共同显示、开关、失败恢复及退出重入正确。
3. 实际 GPU 检查太阳近/远景、地球与土星环前后遮挡、银河接缝及恒星发光，不只以编译通过认定视觉完成。
4. 标签测试拥挤总览、近景、天体遮挡、视口变化、稳定渐隐及拾取一致性。
5. 对照原有全部适用 Rust/TS/WASM/资源/Next 与 GPU 回归；记录性能与尚未做的 VR 验收，不伪报完成。
6. 更新 SDK 技能书、版本、CHANGELOG 与证据，提交推送当前分支；gh 非阻塞跟踪对应 CI。
