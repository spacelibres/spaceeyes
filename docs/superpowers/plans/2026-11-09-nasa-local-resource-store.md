# NASA 本地资源库实施计划

依据已确认的 `docs/superpowers/specs/2026-11-09-nasa-local-resource-store.md`。每批完成后执行适用完整检查、补丁版本加一、更新 CHANGELOG、提交推送并跟踪 CI；未经逐项核验的缺口不得标记完整。

## 一、静态资源持久化

- 为服务器静态源文件和恒星文件建立有明确来源、长度及 SHA-256 的持久目录，读取时先校验并优先复用已存在的已审核缓存；不使用临时模型转换缓存的自动清理策略。银河瓦片、行星原有本地来源保持兼容。
- 新增可重复执行的准备命令，遍历登记的源清单，先导入已有匹配缓存，再有界下载缺项，原子写入与报告失败；失败不破坏已完成项。初始准备范围包含登记贴图、模型依赖、星表及阶段/父体依赖。
- 测试离线读取、长度/散列损坏、缺失与回退、取消和重启持久化；对本机全部已登记静态源完成核验和准备并记录数量。真实浏览器验证原有地球/卫星场景和资源按需加载。

## 二、DYN 本地读取和增量持久化

- 为 DYN 原始字节建立持久存储，安全限制来源 URL 和路径，有界读取；支持显式配置只读旧镜像及项目可写增量库。先读取本地，未命中才按既有策略获取并持久化；严格离线模式缺失时明确失败。将读取和写入放在既有取消、并发、格式/窗口审查与来源记录之内。
- 使用临时目录和可控 fetch 测试命中、缺失、损坏、穿越、并发、取消、重启和原始字节一致性；对地球、月球、ISS、LRO、火星和跨行星任务离线回归同一时刻、相机及覆盖，不改变轨道语义。

## 三、全量准备和覆盖审计

- 递归遍历每个已登记轨道及姿态根索引和子分段，校验完整性、来源/散列与实际覆盖，复用已有约 279 万文件；报告已验证、缺失、源无覆盖、已审核异常及下载失败，允许断点续跑。静态清单、转换资源与 1949—2049 范围一并列出缺口。
- 验证断网下代表对象、主要系统、切换及正反播放，记录资源请求、CPU/内存、GPU/显存、长帧以及 NASA 对标结果；不能用不可用数据或无 GPU 测试冒充全量通过。
- 提供明确的手动增量更新和快照切换，避免自动覆盖运行中的科学数据；数据资源不提交 Git、不放入 WASM。
