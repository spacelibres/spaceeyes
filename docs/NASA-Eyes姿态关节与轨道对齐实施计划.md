# NASA Eyes姿态、关节与轨道对齐实施计划

2026-10-31。用户已明确要求自动继续、逐项对照NASA Eyes。本计划沿当前架构执行，不重复请求同范围授权，不操作冻结分支。

- [x] 天然卫星使用父体相对完整瞬时轨道（按真实轨道记录推导）；人造卫星/航天器使用过去时间拖尾，分别由轨道/拖尾开关控制。全周期不足的真实轨迹不伪造闭合。
- [x] 受控visual.joints发布最多32个命名模型节点的单轴对日约束：joint、hingeAxis、normalAxis、targetDirectionIcrf。仅visual权限且对象归属正确、仅模型；单位向量/垂直轴/有限数/重复名严格校验，空列表清理。Rust/WASM独立校验；不暴露Bevy实体或脚本。
- [x] TS按源目录25条关节align的有效覆盖与声明顺序生成约束。25条均为primary none锁转轴、secondary point sun。科学目标方向由TS当前星历计算；核心只按模型祖先旋转和关节本地轴求图形旋转。嵌套关节依父子顺序，保留绑定平移与缩放，不逐帧累加漂移；暂停/跳时/倒播可重现。
- [x] Rust在GLTF实例就绪后查找实际命名节点（普通节点或skin joint），相机坐标变换只施于ICRF方向，不重复旋转模型；关节动画在Bevy动画后、Transform传播前应用。缺名/多义名/无有效机身姿态明确报告，不能假称已对日；资源替换及退出恢复/清理。
- [x] 核对实体DYN/fixed/align/spin姿态；已给定科学姿态不能用统一朝向代替。源缺覆盖、未知控制器不能静默当作姿态齐备。固定帆板随源机身姿态对日，不凭空给没有转轴的模型造关节。
- [ ] 验证SDK权限/生命周期/真实WASM、真实25控制器与模型名、嵌套关节投影对日、轨道分类、ISS等代表实际GPU。每个已验证里程碑补丁版本、CHANGELOG、提交推送及gh检查。

关节单轴受机械转轴约束时，目标是帆板法向在可转平面内最接近太阳方向，不谎称所有姿态下都能无约束正对太阳。NASA交互对照使用全局审查路线持续逐项记录，不以一批完成声称全部习惯完全一致。


真实模型核验：25条控制器分布12个模型，均没有内置animation clips或skin，属于命名刚体节点关节。ISS十条控制器按Three.PropertyBinding名称规范化（空白转下划线、去除[].:/）唯一匹配；同一规范化键的重复约束被SDK及Rust拒绝，模型多义名明确拒绝。NOAA20/21补真实模型依赖散列，并从已有完整源定义加入派生发现目录；原始抓取目录JSON不改。

更新顺序：每帧先将已控节点的绑定旋转作为求值基线，再按实际深度覆盖有效约束，保证外层约束移除时内层同帧使用恢复后的父体；不把上一帧控制角当作新的绑定姿态。实体spin使用源周期及轴参考，本地轴右乘、世界轴左乘；无绝对相位以首次有效求值时刻为可视化零点并披露，锚点受retain/checkpoint/dispose约束。

本版本地与代表GPU均已通过；最后一项的远端Actions结果以提交后gh核验为准，不提前标为成功。
