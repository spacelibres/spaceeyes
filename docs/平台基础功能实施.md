# 平台基础功能实施

依据：太空之眼平台架构书、第一版规划与验收。当前工作分支为 `codex/bevy-planning`，本实施不依赖冻结开发分支。

平台基础建设服务全部天体和任务插件，不把资源格式实验或个别天体页面当作平台主体。以下是原规划的实施分解，不变更架构和第一版范围。

| 基础能力 | 责任与依赖 | 验收依据 | 当前状态 |
| --- | --- | --- | --- |
| 插件宿主 | TS 注册、兼容检查、授权、启停及清理；不持有场景权威状态 | 启停、失败回滚、授权及旧会话失效测试 | 已有进程内启停、整体关闭及在途任务清理；已接入太阳系正式页面，路由与退出清理等待本轮集中复验 |
| 受控 SDK | 宿主校验调用及资源归属，Rust 核心再次验证结构化输入；同步技能书 | 非法调用被拒绝、跨插件资源不可修改、错误可追踪 | 已接通真实 Rust WASM，含数据、时间、聚焦及 scene.visual 资源表示/状态；不开放 Bevy 内部句柄 |
| 三维核心 | Rust/Bevy→WASM；通用场景、资产、相机、光照、选择和卸载 | 浏览器实际加载、GPU 画面和资源释放证据 | 已接入 Bevy 0.19.1、受控模型/贴图和异步状态；已接通真实六面表面纹理、土星环、姿态与轨迹显示；完整 NASA Eyes 效果待验收 |
| 对象与科学状态契约 | 通用对象标识、时间尺度、参考系、单位、来源及覆盖；科学状态与显示坐标分离 | 数据可追溯、覆盖外明确失败、Rust 验证转换输入 | 已有 ICRF/千米/TDB 采样状态、归属及局部原点显示转换；已接通姿态与轨迹输入，科学精度待验收 |
| 时间与相机协作 | TS 提交操作意图，核心执行；数据插件按统一时间求值 | 暂停、播放、跳时、聚焦、跟随及尺度稳定性 | 统一时钟与 SDK 控制已验证；基础聚焦、环绕和缩放已实测，完整 NASA Eyes 相机交互尚未验收 |
| 资源服务与数据插件 | 受控获取、缓存、取消、解码、求值和生命周期归属 | 真数据、失败反馈、过期结果拒绝及停用清理 | 已有固定资源包校验和核心资产目录/修订归属；测试服务不等于生产资源服务，真实 DYN 运行时获取/求值已接通；CMTS 未作为本批完成声明 |
| Next.js 工作区 | 承载三维画布、对象目录、信息、图层、时间控件及插件状态 | 页面与核心状态一致、路由离开与重新进入正确释放 | 已有独立 web 工作区与真实核心接入，主入口已为太阳系多对象与时间/相机/图层流程，旧夹具移至 diagnostics；待集中验收 |
| 构建与集中测试 | 锁定依赖、Rust/TS检查、WASM构建、浏览器/GPU验证及 CI | 按最新用户要求执行适用检查、更新 CHANGELOG 并提交，提交后 gh 复验 | 已有集中核心/工作区检查及 CI，模型与贴图有浏览器局部证据；完整第一版 GPU/性能/科学验收仍未完成 |

实施依赖：先建立插件生命周期和测试，再定义 SDK/核心协作契约及技能书；按契约打通 Rust/Bevy WASM 与 Next.js；随后接入资源服务和数据源插件，补齐时间、相机及面板。契约设计时同时核对所有基础能力，不能各自另起不兼容协议。Proto 的取舍按架构书单独确定，当前 TS 类型不作为已批准的最终公开协议。

## 当前批次 · 0.0.7

主入口已接通总览、目录搜索、太阳与行星及地月关联选择、真实 DYN 位置/姿态求值、聚焦/跟随与观察视角、统一时间、科学来源/覆盖/失败面板、标签/轨迹图层及退出重入清理。Rust/Bevy 持有场景权威，TS 数据插件经受控 SDK 发布状态。旧 Juno 合成技术夹具和格式检查独立放在 diagnostics。

固定资源清单包含十个天体六十个独立表面纹理面及土星环上下纹理，保留来源、长度与 SHA256。动态纹理服务先验证本地缓存，缺失才从固定 NASA 来源获取并核验；无需 public 导出。

科学与视觉验收仍须独立完成：近似星历科学精度未验收；Mars/Venus 当前源时间逆序明确 unsupported，不补造轨道。本轮 96 项自动测试及实际浏览器基础流程、390 像素响应式检查已完成，证据见 docs/evidence/core-0.0.7；鼠标完整自动化、性能及 NASA 全效果尚未验收，不更改第一版完整验收勾选。

准备与集中检查：`pwsh -File tools/prepare-solar-assets.ps1`，随后执行 `pwsh -File tools/check-core.ps1 -Renderer -Workspace -NativeCamera -JunoAssets -SolarAssets`。编译、相机逻辑与资源散列校验不替代真实浏览器 GPU 检查；实际执行结果、提交与 CI 状态由本轮验证记录和 CHANGELOG 追踪。

宿主不加载远程代码、不执行市场安装、不提供同进程 JS 沙箱。核心适配仍为内部边界，不将 TS 类型宣称为已批准的最终公开传输协议。Nyx、STK、完整市场和大模型自动化继续属于后续范围。
