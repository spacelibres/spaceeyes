# 太阳日珥与银河分级实施计划

用户于2026-10-30确认三层太阳及银河分级方案，并提供弧形日珥参考图。

1. 保留NASA表面，降低自发光过曝；核心新增通用stellar弧形细丝表示，球面分布，表面锚定，真实深度遮挡，外置WGSL驱动沿弧流动和温度颜色层次；不添加物理仿真或声称实时观测。
2. 银河保持ICRF方向，先低分辨率后高清，资源外置、白名单、取消和缓存预算；星点保留自身距离。分辨率LOD不伪造太阳系内可见银河平移视差。
3. 验证几何表面锚点、有限数值、预算和生命周期；完整Rust/TS/WASM/Next及实际GPU，检查近远景、环绕遮挡、退出重入和错误日志。
4. 与待完成的深空迭代一起集中核验，更新技能书、CHANGELOG、证据，提交推送当前分支并gh跟踪。冻结分支不动。
