# 太阳系统加载与剩余对齐实施

延续已确认NASA全量航天器接入与全局审查，基线d3b782bb8。

太阳系总览不得只保留baseSolarIds。当前目标为空时按Sun直接子体构建日心飞船集合，八大行星仍优先首批加载，日心飞船后台按需获取；选择局部主星按当前系统集合清理。返回总览、滚轮拉远自动总览和初始化走相同加载规则，不能某入口清成十个对象。图层关闭、真实时刻父体、覆盖/预算/取消仍有效。

继续研究并实现历史分段与姿态控制器对齐：历史求值必须独立且预算有限，不覆盖实时数据/时钟，不得混用不同父体的DYN；姿态按NASA控制器覆盖与顺序执行，有有效align结果时不因不覆盖当前时刻的ori控制器全局失败，明确区分推导/真实姿态。测试先失败，实际资源和GPU验收后逐版本提交。

## 本批执行边界与规则

- 总览：默认无选中对象时以Sun为系统根，八大行星首批保持不变，真实日心飞船后台补齐；返回与自动拉远总览复用相同集合，仍受craft图层/当前父体/源覆盖约束。
- 历史：先支持当前选中航天器的独立历史缓存，最多32历史段、合计200000 decoded cache records，新段加载前分配剩余额度；不宣称此数值是进程全部峰值内存上限。历史源也经过主数据源同一4请求门控；每请求仍16MiB字节限制。切换/retain/关闭拖尾/退出取消并释放，迟到结果不得刷新旧焦点。主对象/时钟/相机不改。
- 坐标：历史目标世界坐标减去当前显示父体在该历史时刻的世界坐标，结果统一提交一个originId。采样包含父体/源分段边界，真实缺口及不连续交接保留断点；预算不足不伪造外推，不直接跨缺口画长弦。
- 姿态：仅单ORI root明确覆盖外才能输出机器可读覆盖元数据；未知HTTP/坏包/多track不确定情况仍失败。覆盖外跳过该DYN控制器，保留按NASA顺序执行的align/fixed/spin；只有关节align不算机身姿态。进入已知ORI覆盖范围时非阻塞刷新，避免派生状态永久覆盖有效ORI。派生姿态明确标识，不声称实测。
- 没有以此宣称故事/比较/工具、全部目录、全部交互像素、科学误差和长期性能已对齐。后续继续按差距矩阵推进，不因这些基础修复删去未完成功能。

真实姿态资源进一步核验：NASA sc_psyche/ori/def.dyn与LRO/ori/def.dyn实际wire type均为quat，不能用目录名ori推断wire记录。quat每样本time+4 quaternion共40字节，按NASA QuatPoint slerp且零角速度求值；对外归一现有ori结构并保留sourceType溯源。Psyche当前时刻在真实ORI覆盖内，应DYN姿态；LRO现代时刻超出其ORI覆盖，应保留有效align派生姿态。未知wire（包括没有格式证据的quat_v2字面类型）不擅自接受，路径名称和wire类型分开。
