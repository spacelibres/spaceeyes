# NASA 相机比例与北向修正

沿用已批准的NASA相机逐函数对齐方案。本批修正已观察到的LRO角度/比例问题，不改轨道、光照、姿态、科学尺寸和任务镜头意图。

## 来源与责任

- CameraScripts.goToSpacecraft：目标相对父体径向确定初始视线，父体姿态Z轴作为上方；日心任务采用黄道法向。本批优先修正已有明确父体任务的北向，保留巡天/对主星的既有已确认方向。
- Cameras.getDistanceToFitEntities：以实体原点与目录extentsRadius取景。当前代码虽用目录半径，却继续使用动态AABB中心，混合了两套焦点。目录半径有效时跳过AABB求中心，不因关节动画或模型偏心持续漂移。
- ZoomController.__update：缩放离地高度，非球心距离。球形表面按科学半径计算离地高度，航天器/总览无地面时保持径向缩放；所有路径保留碰撞检测和惯性。

## 实施顺序

1. 原生最小Bevy回归先复现倾斜父体北向、偏心模型目录焦点、行星近地缩放三个失败。
2. renderer中保留稳定的相机北向基，在局部基内求初始yaw/pitch，手动转动不重置；预设视角和Follow保持原语义；System采用源码默认25°参考平面抬升并保留进入前方位。
3. 目录半径优先；没有目录半径的现有AABB回退不改。
4. 同一缩放数学入口供UI/鼠标使用，基于表面高度，模型与总览不加虚构地面。
5. 全套Rust/TS/WASM/资源及GPU验证，LRO同一时刻截图；同时复测行星、其它主星卫星、系统/跟随与预设，不声明未经完成的NASA像素一模一样。

## 边界

真实黄道法向、NASA定制距离/偏角、完整过渡动作若尚未接入，须明确记录，不以固定世界Y声称全部对齐。spacelibre既有SVG与UI配色保持。


## 独立审查补正

系统模式的包围拟合与实际镜头必须使用相同的有效北向基；新增倾斜北轴、非对称成员回归，先复现距离不一致再修正。Follow排除自动向阳近景回退，保留原独立构图。

实际GPU复测识别System缺少源码_goToSystem默认25°俯角：补回以父体/天体北轴为法向的平面投影，保留进入前相机方位角并抬高25°；新增边界断言先失败，拟合仍使用同一实际相机基。
