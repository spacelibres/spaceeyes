# NASA Eyes 显示比例与轨道悬停对齐

依据：平台架构书、第一版 NASA Eyes 基线及本地 `C:/Users/stone/Documents/solarsystem/eyes`。本轮保持科学位置、物理半径、轨道、姿态及 TS 数据插件边界，调整显示取景和交互反馈。

## 比例关系审查

| 层次 | 本地 NASA 依据 | 本平台处理 |
|---|---|---|
| 科学空间比例 | 同一实体位置、半径及父体参考 | 保留统一千米坐标和浮动原点，不压缩轨道，不放大卫星实体 |
| 单体取景 | CameraScripts.goToCelestialObject / goToSpacecraft 的 1.3 倍余量 | Nearby 采用同样余量，保留已有模型外廓、长边 FOV 和防穿透 |
| 系统取景 | Cameras.getDistanceToFitEntities 分别拟合成员的横纵投影与外廓 | 替换包住整组的大球估计，计入环外径及声明的模型取景范围 |
| 主星与卫星组 | CameraScripts._goToSystem 以主星及自然子体构图，排除普通 sc 子体 | 保持当前同父体主要天然卫星的 System 构图，不让远处航天器拉小主星 |
| 系统最小距离 | CameraScripts._customSystemDistances | 采用源代码八个行星的显示距离下限，属于取景策略，不属于轨道参数 |
| 运动及窗口变化 | 相机过渡计算目的构图后交互 | 系统取景在进入时确定，卫星运动不反复抽动缩放；窗口比例变化重新拟合并保留相对缩放 |
| 远景标记和标签 | 可见区间、类别权重及固定锚点 | 保持 0.0.51 的可见性与碰撞隐藏，不改回标签搬位 |

转换到相机坐标、相机位于正 Z 后，对每个成员中心 `(x,y,z)` 和显示外廓半径 `R` 使用：

`D >= max(abs(x)/tan(h) + R/sin(h) + z, abs(y)/tan(v) + R/sin(v) + z)`。

这里 `h/v` 是横纵半视场角；随后乘 1.3，并应用系统最小距离。不能用改变星球尺寸代替正确取景。Follow 保持之前已验证的相机与参考对象关系，不套用其他模式的相机位移。

源显示距离下限（km）：水星 425648、金星 862136、地球 1040264、火星 80000、木星 7157638、土星 4869142、天王星 1886367、海王星 2407045。它们是当前本地 NASA 代码中的体验参数，不是天文学常量。

## 悬停交互

参考 `TrailManager.onHoverChange`：鼠标命中当前可见的天体、标记或标签时，只提高该对象轨道/拖尾的透明度和线宽。普通轨道 1.2 px，悬停 2 px；拖尾峰值线宽 2 px，悬停 4 px。默认普通层、悬停层分开，不修改其他对象或全局 Gizmos 配置。

命中采用当前帧身体投影及仍可见的标签区域；星环额外使用相机射线与三维环平面求交，支持透视及中心出屏的可见环带，环孔和外部空白不算命中。移出、无命中、拖动或对象失效时清除。高亮不切换选择，不移动相机，不改科学时间，也不强行显示已关闭或按近景策略隐藏的轨道。

天然卫星完整解析轨道继续闭合绘制；航天器仍显示过去的有效轨迹，保留渐隐、断点及三维深度。当前使用天体/标签有界命中区、三维环带求交和拖尾峰值线宽，不宣称逐三角形/环贴图透明像素拾取或 NASA 逐顶点线宽收尖已完整移植。

覆盖投影拟合、宽屏/竖屏、星环和模型范围、八个系统距离、相机随卫星运动保持稳定、窗口重拟合不改科学位置、命中/离开/拖动清理、环带空洞及独立线宽组。实际场景与悬停截图、完整检查见 `docs/evidence/nasa-framing-hover-0.0.52/`。
