# 太阳观测约束与三维重建设计

状态：用户已确认阶段 A 整体实现；实现与本地验收记录见 docs/evidence/solar-observation-0.0.31。阶段 B 尚未授权。日期：2026-10-31。

## 目标与平台边界

以用户提供的完整橙色太阳照片为效果参考：细密表面、橙红暗部、金黄和少量黄白活动区、局部立体日珥。保留旋转、缩放、按距离加载与手动调参。

遵循《太空之眼平台架构书》：TS插件提供数据与配置，受控SDK传入Rust/Bevy，外置WGSL显示。较重的太阳NLTE/MHD计算使用独立计算模块，不编进浏览器WASM，也不交给负责航天动力学的Nyx。

### 自洽初始化示例：项目推导，非原文默认值

取T=8000K、ne=10^16m^-3、q=0.5、B=0.001T；只计氢，假设ne=np：

- 电离分数x=q/(1+q)=1/3。
- 总粒子密度n_tot=ne(2+1/q)，气压p=n_tot k_B T=0.0044180768Pa=0.044180768dyn/cm²，落在上述观测范围内。
- 质量密度ρ=m_p ne(1+1/q)约5.01787×10^-11kg/m³，忽略电子质量。
- 单流体耦合近似下v_A=B/√(μ0ρ)约125.93km/s，β=2μ0p/B²约0.0111。
- 取现有名义R☉=695700km，26000km高度对应0.03737R；300km细丝直径对应0.0004312R。

此例不含氦和离子中性粒子漂移，只作单位、量级和初始化一致性检查，不是磁平衡解。

## 算法到显示的映射

### 全盘表面

建立连续三维表面辐射强度场，分别描述暗背景、细尺度纹理和有限局部活动区；再作深红→橙→金黄→少量黄白的分段映射。动态扰动沿表面演化，避免整球统一染色。

首版该表面场是程序化视觉模型，S1没有能直接重建整张照片的光球对流算法。用户照片仅作视觉目标，暂不推断其波段、时刻及背面。后续真实SDO/AIA、HMI数据需独立登记来源、时刻、坐标和覆盖；不把正面照片包成完整观测球面。颜色映射不等于温度诊断。

### 局部日珥与细丝输运

采用S1 Fig3、§2.4与S3的拓扑概念，先实现局部、含下凹段的参数化剪切拱廊/磁通绳示意；细丝围绕局部主轴分布，不在整球均匀生成相同圈。

给定真实B场时可跟踪`dx/ds=B(x)/|B(x)|`，工程上可用RK4并做步长收敛测试。只有参数曲线时明确标记“拓扑示意”，不冒充已求解磁场。

密度包沿弧长以`ds/dt=±v(s,t)`输运，相邻细丝可反向；v用km/s，显示时间倍率单列。面积变化时质量输运为`∂(ρA)/∂t+∂(ρvA)/∂s=0`。首版是观测约束的运动学模型，不宣称求解了凝结、重联与爆发触发。

后续求磁静力平衡时需满足`-∇p+ρg+[(∇×B)×B]/μ0=0`和`∇·B=0`，并提供磁图等边界条件；完整计算属于独立模块。

### 发射与吸收

采用S2 §6.4常源函数平板近似：

`I_out = I_in exp(-Δτ) + S[1-exp(-Δτ)]`。

Δτ为当前视线段的光学厚度；若从法向τ出发，先用τ/μ，不能重复乘几何长度。日缘暗背景可以出现发射，盘面强背景上可以出现暗丝；多细丝按深度合成，光球遮挡背面。

PCTR中适用的光学薄碰撞激发成分可用ne²与响应函数描述；不能推广为全部H/He谱线的发射律。完整EUV合成还涉及前景/背景日冕、连续吸收和发射阻塞等项。

第一阶段可用明确标记的平板示意S、χ、τ；不能从RGB任意反推这些量后称为物理结果。

### 非LTE求解与查表

S2 §6.5静态统计平衡形式为：

`Σ(j≠i) n_j P_ji - n_i Σ(j≠i) P_ij = 0`，其中`P=R+C`。

结合粒子数/电荷守恒与辐射转移，采用S2 §7 ALI/MALI及§9短特征线方法。需要原子能级、跃迁率、碰撞系数、入射谱、频率网格、CRD/PRD假设和收敛阈值。S1的参数范围不能替代这些输入。

较重求解放服务器/离线模块，输出有出处与适用域的S、χ等表；TS插件按需获取，Bevy作有界合成。没有真实NLTE结果时不标记为已标定谱线模拟。

## 阶段 A 实施前的具体差距

1. 当前StandardMaterial整体着色缺少独立的暗部、亮区与局部活动区映射。
2. 日珥仍是均匀正弦拱形管束，没有局部磁拓扑和观测尺寸。
3. 默认高度0.07—0.22R约49000—153000km，不能自动当作典型26000km样本。
4. 默认单管截面半径0.003—0.012R，直径约4200—16700km，不能称为150—450km观测单丝。
5. 大范围太阳风噪声可铺满视野；近表面日冕、局部日珥和稀薄远风需要独立显示。
6. 新增科学量需明确单位与独立结构，兼容现有58项及旧存档。

## 推荐实施范围与选项

推荐先做“观测约束的轻量实时重建”，能形成可验证的三维效果。另两条路线是“真实观测数据驱动播放”和“完整NLTE/MHD计算”：前者需要数据与覆盖，后者需要初边值、原子数据及计算模块，后续可接入。

### 阶段A：本轮拟批准的代码

- 外置太阳表面WGSL，近景启用细节，每片元最多4层噪声，局部活动区数量有硬上限。
- 分级辐射强度配色与局部黄白活动区，继续自发光。
- 局部三维细丝、以km定义尺寸、以km/s定义流速、显式视线透射示意；不画均匀燃烧圈。
- 近表面有限日冕与12R远风体积分开；观察效果预设默认关闭大范围浓雾显示，保留太阳风计算。
- 先落实新字段契约及旧58项、localStorage v1、JSON与插件调用的迁移；不静默丢弃用户设置。
- UI标记模型与观测风格；现有“应用参考图配色”继续仅改配色。

### 阶段B：另行确认

接入真实观测、NLTE/MHD结果与波段响应前，核对资源许可、算法版本及验证范围。不由本设计自动授权部署新服务。

## 验收

- 同一近景视角对照参考照片，确认细尺度对比度、局部亮区、橙红暗部及局部日缘结构。
- 旋转和缩放时保持立体、前后遮挡；同一结构对不同背景有发射/吸收差异，不用面向相机的火焰片。
- km、km/s、m^-3、T、K转换及q/x区别有测试；测试透射极限、合成顺序、弧长输运坐标、参考质量密度、几何收敛、权限及配置迁移；不宣称求解质量守恒方程。
- 保留聚焦30Hz/失焦5Hz与距离滞回；顶点、噪声、活动区和缓存有界。可见1080p近景测GPU与帧时间，不以隐藏页截图代替性能验证；超预算降级。
- 完整集中检查、真实GPU回归、CHANGELOG、补丁递增、当前分支提交推送及gh核查CI。冻结分支不改动。
