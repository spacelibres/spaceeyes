# SPACEEYES 项目文档与版本规范

版本：0.0.0｜状态：规划草案｜日期：2026-10-27

## 强制规则
1. 全部受控代码、架构书、规则书、可行性方案书使用统一版本。规划期均为0.0.0；不因讨论或修改文档擅自升级。
2. 经批准发布时只递增最小版本号；100进1：0.0.99→0.1.0，0.99.99→1.0.0。兼容性由SDK/Proto另行治理。
3. 每次代码变更必须同步更新根目录CHANGELOG.md，说明缘由、范围、验证证据、风险及提交关联；无记录不得合并。
4. 架构、对象模型、Proto、SDK、插件权限变化先更新对应MD及ADR；AI代码同样遵守。
5. 所有文档标记状态（规划/待审/批准）、版本、依据和变更历史；未经测试不得写“已验证”。
6. 原参考仓库solarsystem的0.2.73是独立项目历史，不得混作spaceeyes的版本。

## 核心技术纪律
统一Rust核心、多编译目标；统一Next.js/React/TS界面；模块化、面向对象封装；Protobuf唯一公开结构化数据契约；首期NASA Eyes功能优先；最终AI按技能书自主生成插件。插件不得越权或修改核心私有代码。

## 变更控制
规划期记录在CHANGELOG的[Unreleased]中。首次受控发布须经项目负责人批准并同步所有受控成果。
