## 现有能力和范围

- Rust/Bevy 核心编译为 WASM；TypeScript/Next.js 宿主、受控 SDK、目录与 DYN 数据链已存在。Nyx 服务端、完整插件市场和大模型自动化仍属后续范围。
- 静态库曾完成 1,443 项固定来源资源的散列检查；DYN 受控来源支持本地优先、严格离线和分段审计。资源准备完成不等同于全部对象与所有时间均可用。
- 同对象轨迹、相机、标签和数据生命周期已有大量自动与专项浏览器证据；这些证据不能代替整体体验一致性或科学精度验收。

- 旧开发快照 0.0.114 使用 GitHub CI 指定 Rust 1.96 执行 `tools/check-core.ps1 -Renderer -ReleaseWasm -Workspace -NativeCamera` 通过，包含 TypeScript、WASM、生产构建及 169 项原生渲染测试。本机默认 Rust 1.99 的 Clippy 对既有 starfield 代码发出新警告，严格检查未通过。

- 新仓库 GitHub Actions 的结果以新初始提交的实际运行记录为准；历史 CI 结果不可移植或冒称新仓库通过。未对全部第三方内容、所有对象和全部历史时间做穷举。
