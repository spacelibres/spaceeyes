# 卫星聚焦时保留所属系统轨道

用户已确认这是问题：选中卫星后，保留所属主星及同系统卫星的轨道，而不是隐藏其它轨道。此前只检查轨迹originId是否等于当前focus，所以ISS/月球成为focus时，originId=earth的同系统轨迹全部失去保护。

在已有统一渐隐入口上增加观察上下文：当前focus及其有效轨迹声明的真实originId。保留当前对象的直接子体、当前对象所属主星自身的轨道、同一明确父体的其它自然轨道与航天器拖尾。当前对象自己的轨道保持既有近景渐隐；无明确父体时不猜测，不把全宇宙轨道强制常亮。每帧从Core重新读取，宿主在父体及其可用性变化时刷新上下文，轨道图层、缺口、实体遮挡和加载预算不变，不自行编造父体关系；独立SDK上下文见下方图层独立性补充。

先用旧入口复现选中ISS时月球/同级航天器消失，再覆盖Moon/ISS/Io/Titan及Earth/Jupiter/Saturn的父/兄弟/子体/自身/无父体/切换上下文。完整本地检查、独立审查与真实WASM选中卫星后缩放/图层/切换复验；补丁版本、CHANGELOG、提交推送、gh CI。

局部父体系保护不扩展到太阳根sun的所有同级轨道，避免将选中行星等同于观察局部卫星。现有NASA数据省略行星的Sun轨迹originId，但对显式Sun参考也增加防线与失败回归。独立审查提出此边界，已修正。

图层独立性补充：关闭自身轨迹会清除轨迹style，因此不能把视图父体系仅绑定在绘制几何上。扩展已有受控camera.observe options.systemId，作为独立观察上下文；SDK严格校验ID，Rust验证权限及当前有效对象后原子更新。已有Rust调用兼容，JSON字段可选；主体宿主通过统一observe包装传真实就绪父体，所有观察模式沿用旧调用时机，不因图层开关重置相机。核心优先使用独立上下文，兼容旧style回退；删除父体/释放会话清理上下文。新增SDK、真实WASM、宿主独立图层与生命周期测试；SDK补丁递增并写技能书。

跨阶段复验：Cassini关闭自身拖尾后保持同一焦点跨Earth→Sun→Saturn，独立systemId同步变化。普通tick在data.publishAt之后也检查父体变化，不仅依赖configure。
