# 沉浸式工作区实施设计

日期：2026-10-30。依据：平台架构书、第一版规划与验收、全局实施与迭代路线。属于用户已授权的逐步对齐 NASA Eyes 观察体验，不增加第一版范围。

## 本批交付

三维画布覆盖浏览器视口，品牌与主操作置于顶部，播放、速率、当前时间固定在底部。目录、对象信息和日期跳转按需展开，同一时间只显示一个工具面板，面板具有明确关闭按钮，Escape 可关闭。选择目录对象后显示对象信息；返回总览保留既有核心与数据流程。退出和加载失败仍保留重新进入入口。

比较三种执行顺序：先增加视觉特效仍会受限于狭小画布；先实现拾取会增加 SDK 与核心交互契约；先调整工作区能直接改善全部既有场景。因此本批先调整呈现，后续再贯通场景拾取与相机过渡。

不修改 Rust 核心、SDK 科学状态、请求策略、DYN 与贴图来源，不引入新的天体、贴图或第二个时钟。保留 spacelibre 原版标识和既定颜色角色。远景标记注明非真实尺寸。

## 文件与实施步骤

1. `web/app/workspace-view.tsx`：局部面板状态、工具入口、选择后信息面板、可关闭面板和折叠日期控制；状态只管理界面，不复制科学时钟。
2. `web/app/workspace.css`：以工作区类名限定全视口布局、浮层、底栏及窄屏布局；不影响诊断页面。复用原 VI 变量，避免更换品牌资源。
3. `web/app/layout.tsx`：在已有通用样式之后载入工作区样式。网页补丁版本递增，核心版本不变。
4. 执行完整集中检查；真实浏览器验证自动进入、目录选择地球、关闭/重开面板、Escape、播放暂停、日期跳转和窄屏无横向溢出。记录截图、失败与未完成项后更新 CHANGELOG，提交推送并通过 gh 检查对应 CI。

## 验收边界

桌面和窄屏三维画布与视口等大，无需滚动网页寻找画布或时间控件；工具面板内部可滚动，底部控制保持可见。每个工具入口有名称和展开状态。关闭面板不停止场景、不改变目标或时间。触控和键盘可打开关闭面板。

NASA 在线页面本次采集超时，官方介绍只作为沉浸式三维与导航目标的补充来源：https://science.nasa.gov/eyes/ 。本批不宣称像素级复刻、成对视觉验收、场景拾取、LOD、大气或科学精度已完成。
