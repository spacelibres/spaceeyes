# 瞬时轨道显示设计

日期：2026-10-30。依据平台架构书、第一版 NASA Eyes 对标及用户海王星缺口反馈。

## 原因

0.0.16 用 `trajectoryRange` 从当前时刻向前后各采样半个周期，并裁剪到 DYN 覆盖。固定 TDB 846619082.605，海王星记录周期约 166.599 年，裁剪后仅显示 156.470 年，形成明显缺口。覆盖实际约 1900—2100 年；总长度虽超过一个周期，当前时刻居中的窗口仍越过结束边界。移动历史窗口也不能保证受摄动的首尾位置相同。

保留历史路径断口是数据语义正确，但将其当作完整太阳系轨道线不符合已确认的 NASA Eyes 体验。不得通过跨缺口直线、强制圆化或伪造覆盖外科学状态解决。

## 对标与实现

参考用户提供的 solarsystem/eyes 解读源码：`src/engine/components/OrbitLineComponent.js` 使用当前位置、速度及引力参数反求瞬时轨道；`src/engine/controllers/DynamoController.js` 的 OrbPoint 对两个记录传播后的位置、速度分别混合。速度不是混合位置函数的时间导数。参考方法，不复制整套第三方渲染引擎。

独立 TS 数据源对有效当前时刻求值位置、速度及两体引力参数，构造当前状态对应的椭圆。以当前径向和轨道面切向为基底，根据角动量及偏心率向量生成整周几何；同一参数端点精确复用，并包含当前科学位置。按平近点角映射模型时刻，保留原有 Rust 时间连接、颜色、父体、预算和渐隐。一般最多 256 点，目标最多 2048 点。

模型时刻可以超出原星历覆盖，只用来参数化当前瞬时椭圆，不能发布为覆盖外的科学状态。`data.publish` 与 DYN 历史求值的覆盖检查不变。历史采样接口默认继续保持原行为；网页明确选择 instantaneous 模式，信息面板说明瞬时轨道含义。非椭圆、退化或缺少有效引力参数时回到覆盖内路径，不强制闭合。

月球使用相对地球的位置、速度及地月引力参数生成轨道，再由 Rust 平移到地球当前世界位置；不把地球历史运动混进月轨。Bevy 核心仍只负责显示和坐标权威；本批不改 Rust、WASM、架构核心，不涉及 Nyx。

## 验证

先新增短覆盖圆轨道回归，复现旧实现首尾不相等，再实现通过。补充倾斜逆行偏心轨道、角动量/能量退化、无效参数、覆盖外状态拒绝和地心月轨测试。真实 WASM 宿主检查闭合参数与目标切换预算。真实 DYN 的七个可用运动对象全部闭合且包含当前时刻，数值见 `evidence/orbit-closure-0.0.17/measurement.json`。

最终按项目完整命令集中检查，并在实际浏览器检查俯视海王星完整轨道、聚焦/拉远、月轨及时间播放。证据与限制单独记录。瞬时二体几何不是多年实际路径、受摄动预测或科学精度认证。
