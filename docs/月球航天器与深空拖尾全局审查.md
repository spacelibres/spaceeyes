# 月球航天器与深空拖尾全局审查

依据：太空之眼平台架构书、第一版规划与验收、已批准全量NASA卫星航天器接入设计。基线c76efd085，上一版CI41229075641 success。本轮使用系统排错、代码审查和Bevy入口技能；保持TS数据插件经SDK驱动Bevy，不混入服务器计算。

## 确认问题与本轮修复

1. sceneIds把非planet目标都替换成其父体。Moon选择后仅加载Earth子体，排除Moon自己的LRO、Danuri、ARTEMIS。改为同时包含当前目标直接子体和其局部父体系同级对象；保留目录分类、当前时刻父体、128关联目标/256场景预算、依赖闭包、图层及失败状态。不强制加载全部太阳系，表面静态点不伪装轨道器。
2. trail.length=null走本地回退，30天硬截断及按点预算缩短，与NASA TrailComponent._getAutoLength不一致。对航天器自动时长采用轨道周期，非orb采用2π|r×v|/|v|²，保持已有946080000秒上限。自动和明确配置均使用自适应采样维持完整可用时间窗，不因有限点数缩短；真实缺口仍断线。天然卫星解析轨道路径不变。
3. 测试先复现月球LRO缺失、默认深空任务历史不足，再验证图层、同系统轨道、长时间窗和预算。完整检查、实际GPU、独立复审后补丁递增、CHANGELOG、提交推送、gh跟踪。

## 尚未完成的严格对齐项

- 跨父体历史：solar-system.ts的phaseCoverage裁到当前父体阶段；NASA TrailComponent._getIntervalForUpdate按位置覆盖取交集，且_getPositionAndVelocity转换历史父体参考系。当前只持有当前DYN段，不可删除边界后混用另一阶段DYN。需要独立历史分段缓存、历史父体依赖和坐标转换专项，不冒充本轮完成。
- 默认自动时长的NASA能量分支（orb引力参数/偏心率）需进一步核对超曲线、近抛物线与本地周期的等价范围；不把全类型数值一致宣称通过。
- 目录收录不等于所有目标在任意时刻有覆盖。实际失败、任务结束、未知DYN与姿态推导须保留明确信息，不伪造LRO等目标在无覆盖时可见。
- 相机、标签、光照、时间、姿态和骨骼虽有既有回归，完整NASA同时间同视角逐项成对验收仍未完成。新版差距矩阵与本文件记录范围，不将单场景截图充当全平台对齐。

## 源码核对

NASA本地eyes/src/engine/components/TrailComponent.js：_getIntervalForUpdate、_getAutoLength、_getPositionAndVelocity；managers/TrailManager.js：颜色/线宽/透明度；core/Entity-567.js：lengthCoverages选择语义。平台对应solar-system.ts、eyes-trail-policy.ts、solar-workspace.ts及core orbit_lines/trajectory_render，相机/标签仍遵守既有受控接口。
