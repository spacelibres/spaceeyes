# 第一版整体交付批次

日期：2026-10-29。按用户最新要求，完整实现规划内的用户流程后集中测试；不再将各个技术夹具作为产品交付终点。本文件不替代太空之眼平台架构书。

## 同一产品流程

太阳系总览 → 目录搜索/选择 → 聚焦与跟随 → 信息及关联对象 → 暂停、倍速、跳时、当前时间 → 轨迹/标签/图层 → 返回总览 → 离开和重新进入清理。

地球与月球为首个贯通流程，同时按已核验资源定义接入其他行星；覆盖和类型不支持时真实反馈，不伪造轨道或成功状态。数据格式实验和 Juno 合成夹具移出产品主入口。

## 一次贯通的职责

| 层 | 必须完成的连接 |
| --- | --- |
| Rust/Bevy 核心 | 通用对象状态与姿态、模型/星体显示、总览/聚焦/跟随/视角、轨迹与标签图层、双精度局部原点、预算和释放 |
| 受控 SDK | 数据、视觉、时间、相机和图层的实际权限/归属/生命周期校验；技能书与代码同步 |
| 数据插件 | 真实目录、父体和来源；DYN 获取/解析/求值/覆盖与缓存取消；读取核心时刻发布，不能另建 TS 时钟 |
| Next.js 工作区 | 将目录、画布、相机、时间、信息、关联对象和图层组成同一流程；使用批准的 spacelibre VI |
| 集成 | 错误反馈、过期结果拒绝、离开/返回、构建部署入口、集中测试、CHANGELOG 与实际提交/CI 状态 |

## 集中验收

代码接线完成后统一执行 Rust、TS、WASM、网页构建、真实样本及浏览器 GPU/交互回归；发现问题集中修复再完整复验，不将编译通过等同于产品完成。记录真数据来源、科学近似与对照、同时间与视角截图、失败与清理结果。达到适用检查门槛后提交推送当前分支并递增补丁版本，远端 CI 非阻塞核验。

Nyx、STK、完整插件市场及大模型自动生成安装仍是架构明确的后续范围，不混入第一版。未批准的科学误差阈值不事后编造，近似数据和缺失能力必须在产品及验收记录中明确说明。
