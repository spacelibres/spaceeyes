# 着陆近景实际表面碰撞

沿已批准的系统取景→着陆近景→光照材质动画顺序实施。NEAR落点距Eros中心约6.42km，小于其8.42km平均半径；平均半径球把贴地相机推远。显示模型已在0.0.91补齐，本次仅修碰撞，不隐藏主星、不改物理半径、不减画质。

使用Bevy0.19.1公开网格射线相交，SDK显式meshCollision opt-in。仅对审计闭合且静态的自然实体模型启用，当前限Eros；不全局替换开放航天器。几何未就绪时保留球体；当前revision ready且完整CPU网格可用后才采用实际表面。Eros1536三角形、2304焊接边，每条边恰有方向相反的两个面，审计脚本web/scripts/audit-eros-collision.ts。

科学位置及相机保持f64，在主星局部km坐标做相交；避免将AU量级坐标直接转f32。使用当前层级局部矩阵，避免Update里读取尚未传播的GlobalTransform。保留全部模型变换和姿态，复用Mesh顶点，不复制三角形。先做包围范围宽相检测，只有近邻执行射线；远处物体不增加网格遍历。不注册自动MeshPickingPlugin，不引入额外逐指针扫描。

覆盖已有内部重叠恢复、整段运动防穿越及有界切向绕行；多实体约束交替到收敛，未就绪回退保持。相机投影near/far仍包含真实主星，不因航天器米级取景裁去公里级父体。

验收：实际不规则表面外、平均球内的相机不被错误推离；不能穿过真实网格；旋转/非均匀变换与AU位置重基准一致；加载中回退实体保护；NEAR固定时刻实际浏览器可看见航天器与局部背景。完整Rust/TS/WASM/发布构建及关联系统回归，记录实际GPU检查边界，不以单元测试代替视觉验收。
