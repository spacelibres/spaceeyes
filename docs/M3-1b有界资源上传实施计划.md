# M3-1b 有界资源上传实施计划

版本：0.0.1｜状态：实现与定向验收完成，完整/远端按候选SHA核验｜日期：2026-10-27
依据：已批准路线M3、Resources第6节、Proto资源契约、M3-1a；用户要求对照全设计逐项实现与集中测试。

## 目标及约束
保持Rust唯一资源权威、Engine唯一写入、Proto公开边界及1MiB消息限制。先实现原始CPU字节与不透明RGBA8纹理的分块入口，不让TS绕过核心登记资源；不引入PNG/JPEG解码或网络I/O到核心。本次不是完整M3。

采用串行追加、显式完成的上传会话：begin/chunk/finish/cancel，公开查询单会话状态。最大单资源16MiB、单块256KiB、同时最多4个；实际还受宿主CPU/Staging/总额约束。begin预留CPU目标及同尺寸Staging，计数原子；上传内容仅在摘要及类型校验全部通过后发布Ready。每块必须非空、偏移等于当前已收字节、无越界；失败不修改内容。服务端生成含管理器身份与单调序列的会话ID，绑定宿主注入的principal；旧、跨实例、越权会话拒绝，不信任客户端身份。操作沿用请求幂等；新请求重复offset拒绝。幂等历史对上传块仅存会话/偏移/长度/SHA-256指纹，不长期保留块内容；历史耗尽后普通命令仍拒绝，为当前至多4个会话的成功取消及一次Stop提供独立有界回执余量，失败取消不能耗尽此余量。

begin必须携带明确source_id、source_version与32字节SHA-256，均有界；摘要对实际完整字节验证，来源标签不是科学来源认证。SHA-256使用MIT/Apache-2.0开源sha2依赖，不自造算法。Blob格式允许非空字节，RGBA8显式width/height/colorSpace，沿用2048上限及alpha=255验证。网格大包、压缩解码、网络/磁盘执行器及墙钟超时在M3后续子增量实现。

finish缺块拒绝并保留可续传会话；摘要/格式错误不发布Ready，释放该上传CPU/Staging并移除会话。成功将内容转为CPU资产并释放Staging；保存source_id/version/SHA-256到资源记录，恢复再次校验，拒绝篡改。取消释放两类占用并删除未就绪记录；Stop清理所有会话。取消后迟到chunk/finish不可复活资源。导出内部ProjectState不保留上传中记录或上传缓冲，只保留完成资产。单会话只读查询返回已收/总长、格式与来源元数据，不返回内容，不推进时间或消耗命令历史。

宿主UI不在本增量增加；SDK技能书必须列出可用格式、上限、bigint偏移/会话规则、取消和失败处理，禁止把此入口宣称完整加载器或科学来源认证。
