# 全局实施与迭代路线

日期：2026-10-30。依据：太空之眼平台架构书、第一版规划与验收。本文是执行索引，不另立架构、不扩大第一版范围，不替代实际验收。

## 当前整体基线

0.0.10 已贯通总览、对象目录、地月关联、相机意图、统一时间、真实 DYN、表面和环、标签/轨迹及退出重入。发布 WASM 原始 28891934 字节；浏览器实际传输大小取决于响应压缩，不将本地 gzip 测量当作服务器配置。资源按选择触发，默认字体独立提供。对应证据位于 docs/evidence/core-0.0.7 至 core-0.0.10。完整 NASA Eyes 视觉、科学精度、性能和鼠标自动验收尚未完成。

## 分离依据

后续进展：网页 0.0.11 补加载阶段；0.0.12 修正近景缩放限制；0.0.13 补远景标记、标签避让与轨迹层次；网页 0.0.14 调整全窗口画布、可收起工具面板与底部时间控制。它们是具体实现进展，不代表本书阶段或第一版全部验收。下一批继续贯通三维场景拾取、目标同步与相机过渡，再逐项对照表面、日照和环；不会因工作区布局调整跳过这些缺项。

核心 0.0.14 / 网页 0.0.15 补充场景天体、远景标记和避让标签点选，复用目录选择的数据加载与 SDK 聚焦路径；区分点击和拖动。投影圆盘与深度优先是本批拾取范围，尚未完成模型三角形、环拾取和所有遮挡边界。下一批优先核对选择切换、总览返回与视口变化时的相机尺度和过渡，再逐项推进 NASA 视觉对照。

| 内容 | 责任与处理 | 完成依据 |
|---|---|---|
| 模型、表面、环、字体、后续音频 | 服务器独立资源；声明目录不触发下载；实际使用才请求 | 请求清单、散列、失败反馈与清理 |
| DYN 轨道与姿态 | 独立 TS 数据源插件；总览取必要轨道，选中后取姿态 | 来源、有效范围、缓存、统一核心时刻 |
| DYN 解码和求值重任务 | 下一批评估独立 Worker，先确定消息、取消、预算和旧结果隔离 | 确认主线程收益且不产生第二个科学时钟后实施 |
| 对象目录、介绍和关联信息 | 属于数据源与领域插件；按已验证来源逐步从宿主配置分离 | 真实目录证据及受控数据契约；不随意开放远程代码 |
| 渲染、相机、坐标变换、着色器与程序常量 | Rust/Bevy 核心；不为减小包而拆散引擎算法 | 场景一致性、数值边界与实际 GPU 回归 |
| Nyx/STK、市场、大模型自动化 | 保留架构边界，第一版不实现 | 后续独立设计与验收 |

资源外置不是一次下载整个资源目录。已触发资源可以复用；新增缓存必须有预算、身份、失效与退出语义。分离工作不得降低纹理分辨率、伪造数据或绕过 SDK 权限。

## 按完整用户流程交付

| 顺序 | 用户可见交付 | 一起考虑的模块 | 验证重点 |
|---|---|---|---|
| 1 加载与恢复 | 打开网站、进入场景、选中对象、失败重试、取消、退出重入均有明确状态 | WASM 初始化、资源服务、数据插件、宿主状态、生命周期 | 冷/暖启动分开测量；取消后不启动迟到渲染器；失败可恢复；请求仅由需求触发 |
| 2 场景操作 | 从目录与三维场景选中同一对象，聚焦/跟随/缩放/视角与面板一致 | Bevy 选择和相机、SDK 意图、宿主输入、数据覆盖 | 真实鼠标与键盘流程；遮挡、无数据、快速切换、缩放极限 |
| 3 视觉基线 | 同对象、同时间、可比视角下逐项对齐 NASA Eyes | 真实姿态、日照、材质、表面、环、标签和轨迹 | 成对截图；日夜面、极区、接缝、环取景；保留调色变更记录 |
| 4 场景扩展 | 按设计书逐步补火星关联任务、木星卫星与航天器 | 资源地图、真实目录、DYN、模型、SDK 与信息面板 | 数据齐备才接入；火星/金星源时间异常先定位，不排序掩盖、不补造轨道 |
| 5 集中验收 | 回归已交付的全部第一版流程 | 上述所有模块 | 固定环境和预先确定阈值；视觉、科学、性能及生命周期各有证据 |

每批先明确场景、真实资源和数据依赖、接口边界、失败路径与验收方法，再实施代码。跨模块能力按完整场景一并交付，不把单个格式解码、单个按钮或单张贴图当成平台完成。

## 0.0.16 场景一致性进展

已完成太阳居中的统一 AU 总览、带时刻的轨迹加密与当前状态连接、地心月轨、天体配色、近景轨迹渐隐、滚轮自动返回总览，以及土星环双面透明受光。集中检查与实际 GPU 证据见 `evidence/orbit-fix-0.0.16/README.md`。后续视觉批次继续核对环阴影、表面与相机效果；不得把本次修复当作 NASA Eyes 全部功能验收。

## 0.0.17 轨道显示语义纠正

太阳系轨道线改为有效当前 DYN 状态对应的瞬时椭圆，参照 NASA Eyes 的轨道显示方法。修复居中历史采样窗口被覆盖裁剪造成的海王星缺口，继续保留历史路径接口与科学覆盖限制；详情见 `瞬时轨道显示设计.md`。不改变 Rust 坐标权威、地月层级、资源策略及第一版边界。

## 0.0.18 当前金星、火星数据恢复

固定源哈希的有序窗口选择恢复当前金星、火星数据，原始记录不排序、不改值，继续严格解码并保留原始/区段溯源与真实有效覆盖。火星源文件部分历史重叠歧义仍拒绝；详情见 `金星火星有效区段接入设计.md`。后续科学核验继续按对象、时段及精度分别验收，不能用“当前可显示”替代全部历史正确性。

## 每批完成条件

1. 读取本书和架构依据，核对当前代码、上版 CI 与未完成事项，禁止操作冻结分支。
2. 一次完成本批协作链路；实现结束后集中运行适用 Rust/TS/WASM、网页构建和资源检查，渲染相关变更补实际 GPU 回归。
3. 核对浏览器请求与画面，分别记录实现、自动测试、GPU、性能和科学验收，缺项不能写成通过。
4. 更新 SDK 技能书、实施状态、证据与 CHANGELOG；实现里程碑递增补丁版本，提交推送当前开发分支。
5. 使用 gh 核验对应提交的 Actions；等待远端检查时继续独立本地工作，失败及时修复。

下一实现批次优先执行第 1 项的加载状态、失败恢复与启动测量；Worker 只在定位到主线程阻塞后纳入同批，不为架构形式新增不必要的消息层。后续迭代必须保持地球—月球—时间控制—总览—退出这一既有流程可回归。
