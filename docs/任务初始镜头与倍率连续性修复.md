# 任务初始镜头与倍率连续性修复

用户明确：选中后保留卫星前景，背景朝天空或被观测主星；提高时间倍率时画面不能卡住。基线9b444aaff。

## 已定位的两项播放问题

1. host.play每次改倍率都lastFrame=undefined。连续滑动倍率、每帧一次onRate时，每个下一帧都按elapsed=0计算，直接丢失时间推进。仅暂停/恢复等状态变化重置时间基线，纯倍率修改保留上一帧时间。测试连续1×/2×/3×/更高每帧切换、暂停恢复及覆盖重载，不把静止截图当作性能证明。
2. renderer配置canvas聚焦约30fps目标、失焦仅5fps；操作时间控件会失去canvas焦点，因此3D明显跳帧。保持可见页面操作面板时同样30fps目标节奏，继续使用有界reactive_low_power，不改成无界Continuous。浏览器后台隐藏仍受浏览器RAF节流。

## 经用户确认的任务初始构图

机身DYN姿态、太阳翼和任务镜头是三个独立概念。NASA goToSpacecraft是外部取景，goToInstrument才使用显式光轴；本轮不把外部构图冒充仪器光轴。增加受控camera.observe nearby可选initialLook:{kind:target|sky,referenceId}，严格验证/快照/权限/有效状态/清理。

宿主登记经确认的巡天任务取景为sky（背向参考父体深空）；持续观测主星者使用target朝当前主星，太阳观测任务显式朝Sun。Chandra/Hubble不能因为通信或姿态参考为Sun/Earth而被误认目标观测，Psyche巡航不能直接锁向未来小行星。没有可靠任务规则时保持普通近景。仅初始focus变更应用一次，之后鼠标环绕、缩放及手动预设不会每帧被拉回。System/Follow/天然天体旧规则不变。
