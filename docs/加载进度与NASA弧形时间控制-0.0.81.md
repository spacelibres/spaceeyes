# 加载进度与NASA弧形时间控制

用户要求改善初始化视觉并采用NASA时间轴；沿用已确认NASA对标与spacelibre VI，不改科学计算或核心渲染。

## 实施清单

1. 初始化发布结构化阶段：模块、WASM、目录、行星数据、渲染启动；只有真实完成才能推进，明确为阶段进度而非下载字节百分比。八大行星资源状态单独显示；失败/取消不显示完成，无虚假定时器，不人为等待。
2. 独立加载组件，品牌图形、连续进度线、阶段清单、当前状态、取消；故障保留重试。减少动态效果偏好时关闭装饰动画。
3. 对照本地TimeControls.js与模板：底部无大卡片，日期左/时刻右，中央倍率，SVG弧线与发光旋钮；倍率滑块控制时间流速而非日期。保留101档倍率表、暂停恢复、正倒放、回到1倍、LIVE/当前时间及日期跳转。NASA曲线M0,0 C60,50 540,50 600,0，旋钮按原公式定位。
4. 新组件不直接操作核心，仅调用现有宿主回调。拖动操作即时显示，向宿主最多每200ms发送一次，松开/键盘完成提交最终值，卸载清理。键盘和触摸均可用；状态颜色使用VI角色，品牌SVG不改几何。
5. 先测真实启动阶段通知、曲线端点/中心及有效时间格式，再实现；集中跑项目适用检查，桌面/窄屏截图和键盘/时间操作验收，独立审查，版本与CHANGELOG提交推送。

不将渲染器启动完成称作全部高清资源或GPU首帧就绪；后台星空/银河仍按原策略加载，不以等待全部资源来阻塞入口。
