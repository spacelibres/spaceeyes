# M2-2 同帧拾取与选择反馈实施计划

版本：0.0.1｜状态：实现与验收完成，随实现提交｜依据：已批准ADR、开发进度M2-2｜日期：2026-10-27

目标：浏览器点击最近成功呈现的画面，经公开Proto查询取得同一帧的对象摘要，提供命中、空白与失效反馈。

架构：Rust保存一个最近成功呈现帧的只读拾取视图，包含PreparedFrame及单帧对象摘要；仅成功呈现后替换，不维护第二套权威场景。查询必须携带精确帧序号，返回同帧摘要而非混入当前状态；任何核心状态修订使该视图失效。TS通过SDK查询并展示，CSS坐标归一化成NDC，不计算几何。浏览器在串行处理点击时选择最近完成的呈现帧，排队期间尺寸变化则要求重选，不猜测在途GPU帧。

技术：既有Rust/wgpu、Protobuf、TS SDK、Next.js/React、Playwright。保持统一0.0.1、MIT和原Proto编号；不更改已批准ADR。受信任宿主负责授权；同帧缓存不代表新的权限边界。选择状态属于宿主临时交互，不持久化为核心对象。
