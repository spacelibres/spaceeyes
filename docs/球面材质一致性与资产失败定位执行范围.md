# 球面材质一致性与资产失败定位：执行范围

2026-10-31，接续NASA-Eyes整体体验基线，当前基线核心0.0.46/网页0.0.55。用户已要求按下一批继续。

资源与显示是同一批工作。本内部里程碑先修复三种球面资源表示的材质策略分叉，并补齐六面贴图失败可追溯性；不是全部材质通道或NASA视觉验收完成。

## 已核对与方案

NASA恢复的SpheroidLODComponent通过MaterialUtils统一创建各面材质、设置通道与阴影选项。当前Bevy六面/纯色球面走默认粗糙度0.5，单图球面为0.9，资源表示变化会改变反光。

采用共享球面材质构造规则，沿用已有单图路径0.9粗糙度、非金属和显式发光参数。0.9是当前平台无镜面通道时的一致性回退值，不冒称NASA实测参数；地球海陆分区仍需正确镜面数据。保留恒星unlit及当前增益，普通天体不新增自发光。

不采用全局提高环境光/曝光，会联动改变天空、星环、航天器与太阳；不把night/normal/specular/decal烘焙成颜色，它们有不同空间和光学语义。后续逐通道在受控SDK、数据校验、就绪及显存预算中接入。

## 生命周期契约

纹理是否加载成功不能更改材质的光学策略。纯色/单图/六面仅决定纹理绑定与就绪时机。六面加载失败时返回具体面序号、AssetServer路径与原始错误；保持failed锁定和旧revision拒绝，不因缓存或晚到结果覆盖失败。模型glTF、星环专用材质、太阳动态WGSL、灯光和相机均不由本次公共球面构造接管。

## 验证顺序

先用实际attach_visuals系统覆盖三种路径复现粗糙度差异，修复后保持非金属、非自发光和星体独立语义。测试六面失败定位及旧revision/failed保护。重新执行全部本地检查、独立审查，重启生产服务并连续验证地月、ISS恢复、MRO、木星、土星、图层、太阳、退出重入。分别记录代码验证、运行日志和NASA成对视觉对照，未完成项不得称通过。

## 后续通道的具体约束

- color：sRGB颜色，现有六面朝向转换继续复用。
- normal：不是颜色；需确认来源编码与每个CubeFace的切线基，再转到球面切线空间。禁止直接当作球面法线贴图而忽略基变换。
- specular：NASA恢复着色器单独读取红通道控制镜面强度。不能直接当作Bevy金属度，海陆分区需要明确、受测的PBR映射。
- night：来源根据漫反射照明的暗度混合夜景，且夜景可独立发光。仅给StandardMaterial整球加发光会让白昼也出现夜景，必须保留昼夜门控。
- decal：来源按自身alpha合成，通常为云层；不等于法线或自发光，不得吞掉底层表面就绪状态。

这些通道后续均需受控asset ID、源哈希、相同UV/朝向、资源生命周期和完整就绪定义；不直接开放Bevy材质给TS插件。当前内部里程碑未新增SDK字段或伪造上述通道支持。
