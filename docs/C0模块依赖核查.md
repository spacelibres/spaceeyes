# C0模块依赖与接口核查

版本：0.0.0｜状态：设计依赖图已检查，实际Cargo待验证｜日期：2026-10-27

## 建议依赖图
foundation -> time
foundation -> spatial
foundation -> resources
foundation -> scene
scene/time/spatial/resources -> simulation
foundation/resources/snapshot-types -> rendering
scene/time/spatial/resources/simulation/rendering -> engine
engine/generated-proto -> protocol-adapter
engine/protocol-adapter -> wasm
engine/protocol-adapter -> native

箭头表示被依赖模块指向使用者。snapshot-types必须是只读值类型，不能依赖engine、simulation或rendering，以防循环。

## 静态设计检查
所有依赖从基础层流向组合层，无反向路径。Rendering不依赖Simulation可变状态；Scene不依赖Spatial的可变图；Time不依赖Scene。此图作为未来Cargo workspace的依赖约束。
