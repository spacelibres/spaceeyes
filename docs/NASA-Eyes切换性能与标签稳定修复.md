# NASA Eyes 切换性能与标签稳定修复

本轮范围：目标切换不再等待关联对象；标签碰撞避让保留稳定位置。遵循平台架构，数据调度在 TS 宿主，投影和标签在 Bevy 核心。

## 本地参考

参考目录为 `C:/Users/stone/Documents/solarsystem/eyes`，只读，不修改参考源码。

- `src/engine/core/CameraScripts.js` 的 `goToCelestialObject`：以目标和恒星确定构图，随后执行相机过渡；没有等待整套关联场景资源的前置步骤。
- `src/engine/core/LabelQuadtree.js` 的 `update`：保留标签对象，采用稳定优先级和遮挡状态，每次最多更新 20 项，不以反复创建对象处理遮挡。

本轮借鉴上述调度和生命周期原则。NASA 原实现采用优先级遮挡，本平台还保留用户要求的标签移位避让；不宣称算法完全一致。

## 实现

选择天体时先加载所选目标和父体依赖，完成构图并解除忙碌状态；关联天体继续异步加载。异步结果同时检查工作区生命周期、取消信号和选择版本，发布采用当前科学时刻，禁止旧请求抢回焦点或倒退时间。所选目标不可用时保持其错误诊断，不用后台递归加载覆盖失败状态。

标签保留相对于投影锚点的避让位置。只有实际碰撞或越界时才重新选位；原位置采用较小的分离余量，新位置采用较大余量。仍执行真实字体尺寸、窗口边界、天体遮挡和距离渐隐。临时不可见的标签隐藏并保留实体及字体测量，真正移除的注释才销毁。禁用自动换行，避免边缘换行引发测量反馈。
