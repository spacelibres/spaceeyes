# 主宿星与卫星轨道缩放显示规则

用户明确：放大缩小主宿星时，只让主宿星自身的上级轨道按相机远近渐隐，其天然卫星轨道和人造卫星拖尾保持显示。

统一按受控轨迹style.originId与当前focusedObject判断直接父子关系，不按画面距离猜测，不区分天然轨道与航天器拖尾。子体轨迹同时绕过相机半径渐隐和轨道尺度渐隐两层；主宿星自身上级轨道沿用原渐隐。图层关闭、源无覆盖、真实断点、视锥和实体遮挡继续生效。切换对象时即时重新判断父体，不保留旧主星的保护状态，不改科学数据、加载预算及相机控制。

先增加天然卫星在两层渐隐下仍显示的失败回归，再实现统一可见性入口；测试Earth/Moon、Jupiter/Io、Saturn/Titan、航天器和主星轨道、对象切换、图层。执行全部适用本地检查、最终WASM GPU复验，递增版本与CHANGELOG，提交推送并用gh检查CI。
