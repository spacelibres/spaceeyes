# M2-3 相机聚焦与目标参考系跟随实施计划

版本：0.0.1｜状态：实现与验收完成，随实现提交｜日期：2026-10-27
依据：ADR-007、Rendering规范、开发进度M2路线；本轮不改变已批准模块职责或版本治理。

目标：选中对象后通过公开命令聚焦或跟随，并从Rust查询相机状态。自由视角恢复通过已有SetCamera命令清除跟随。每个增量完成验证后单独提交。

## 契约与边界

新增camera.focus命令（相机ID、目标ID、正有限米制距离、follow标志），要求当前Scene修订和TimeGeneration。Engine在当前显式时刻读取目标参考系和几何中心，以目标局部+Z方向放置相机，沿-Z观察。距离必须在已有相机近远裁剪区间内，不自动改变投影或承诺整个模型完全入画。

球体中心为参考系原点；网格中心取引用顶点AABB中心；标记使用参考系原点。不依赖Scene ParentId，也不把网格顶点偏移当成天体科学位置。聚焦只提交一次相机位姿；跟随将CameraTracking(targetId,distanceM)保存在Scene，Renderer每帧从同一个FrameSnapshot求目标中心与姿态，派生目标参考系相对视角，不写Scene或累计帧间状态。

跟随只接受存在的非相机目标，禁止自引用和相机跟随链。跟随目标删除或改成相机时整批事务拒绝；可先用SetCamera清除跟随再删除。参考系或时间覆盖缺失时明确失败，不伪造原点。项目内部快照保存跟随参数，不保存GPU状态。query.camera_state读取逻辑状态，不推进时间或消耗命令历史；不把聚焦时保存的基础位姿冒充跟随后的实时世界位置。
