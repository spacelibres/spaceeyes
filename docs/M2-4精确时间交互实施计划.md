# M2-4 精确时间交互实施计划

版本：0.0.1｜状态：实现与验收完成，随实现提交｜依据：M2浏览器交互出口、Time规范及既有公开协议｜日期：2026-10-27

目标：经现有time.set_rate、time.step、time.seek补齐浏览器基本时间交互，保持Rust唯一时钟。输入为当前显式历元的相对秒，不是UTC日期。

## 契约

宿主提供正反向倍速、暂停时±1秒步进、十进制秒跳转。倍速直接使用核心返回的有理数读数，修改倍速不自动播放。步进/跳转仅在暂停时操作；UI禁用且宿主处理时再检查。输入最多64字符，小数最多9位；使用BigInt转换为Proto的floor秒和非负纳秒，拒绝科学计数法、无效字符和超出sint64秒范围的时间。不用number表示总纳秒，也不读取系统时钟。

负时间格式由总纳秒符号决定，例如seconds=-1,nanos=500000000显示-0.500000000。Seek沿用核心当前timeScale及epochId，提交当前修订与TimeGeneration，完成后从Rust重新查询；不得从输入文本推断操作成功。非法输入/预期核心拒绝显示非致命提示且保留时钟。步进/跳转清除旧选择，迟到结果继续由核心代次和目标时刻校验。
