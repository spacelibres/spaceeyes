# SPACEEYES 科学时间语义核验计划与决策边界

版本：0.0.0｜状态：待实证｜日期：2026-10-27

## 已可确定
TimeInstant必须显式携带time_scale、epoch_id、seconds、nanos；秒与亚秒须规范化，禁止将JavaScript Date毫秒作为唯一科学时刻。空间数据携带FrameId和单位。UTC转换涉及闰秒，TT与TDB不等同。

## 尚未由当前材料证明
现有DYN所有类型的时间值是否统一以J2000 TT秒表示；各控制器的时间尺度/历元是否一致；NASA Eyes内部插值对时间尺度转换的具体处理；完整支持时间范围和容差。

## 验证程序
1. 固定solarsystem的具体Git commit与真实DYN样本SHA-256。
2. 检查parse.ts、loader.ts、ephemeris.ts及测试中的时间字段与注释，记录每一条推断证据。
3. 为地球、月球、木星系统挑选多个历元和跨段边界，计算现有TS实现的状态。
4. 与独立NASA/JPL星历在相同参考系、历元与时间尺度下比较，分别测试TT/TDB候选解释。
5. 检查闰秒、J2000零点、反向播放、超出覆盖区间与极端日期。
6. 生成数值差异、时间偏移与误差预算报告后，才决定唯一规范时间尺度与Proto枚举含义。

## 阶段结论
在完成以上实证前，允许设计字段结构但不得宣称TT或TDB已被证实为DYN唯一时间尺度；不得冻结epoch_id含义。项目版本保持0.0.0。
