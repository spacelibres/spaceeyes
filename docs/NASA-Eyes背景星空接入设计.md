# NASA Eyes 背景星空接入设计

日期：2026-10-30。状态：用户已确认并完成实现；实际数据、WASM 与 GPU 证据见 evidence/eyes-stars-0.0.20/README.md。分支 codex/bevy-planning，冻结分支不动。

依据平台架构书、第一版规划与验收及用户提供的七个 NASA Eyes 文件。目标是三维工作区真实背景星空，继续使用 Rust/Bevy 显示、独立 TS 数据插件和受控 SDK；资源不打包进 WASM。

## 二进制布局

Reader 使用小端。头为 int32 记录数 N，必须非负且不超过预算；文件严格满足 `4 + N * 23`，不容忍截断、尾部垃圾或自行补齐。

| 记录内字节偏移 | 类型 | 来源字段 |
|---|---|---|
| 0 | float32 | mag，源视星等 |
| 4 | float32 | absMag，源绝对星等字段 |
| 8 | uint8 × 3 | RGB |
| 11 | float32 × 3 | 原始位置 a、b、c |

源码依据是用户指定参考仓库的 `eyes/src/engine/components/StarfieldComponent.js` 与 `eyes/src/engine/core/Reader.js`，只静态读取，不运行恢复代码。解析保留原始字段与来源哈希；非有限字段、全黑颜色、零长度位置明确拒绝。

## 坐标与亮度

源先重排 `v=(c,-a,b)`，再施加黄道 J2000 至赤道 J2000 的绕 X 旋转。Pioneer 四元数为 **wxyz**：`(0.9791532214288992,0.2031230389823101,0,0)`，约 23.439°；不能当成 xyzw。插件输出赤道 J2000 方向/位置，核心沿用既有显示基变换 `B(x,y,z)=(x,z,-y)`，转换只做一次。

源着色器以 km 解释距离。43335/43878 条记录的距离模数关系在 0.1% 内相符；543 条恒星记录存在源距离与星等的不一致，部分远距值近似固定上限。保留两种原始字段，不按视星等反推并覆盖原坐标，也不将此数据称为独立科学精度认证。星系尤其只作为源提供的点式背景表示。

颜色按源规则除以最大 RGB 通道。亮度沿用源绝对星等和观察距离的光通量关系：`L=3.0128e28*10^(-0.4*M)`，`F=L/(4*pi*dKm^2)`，`brightness=2*log1p(F*1e4)`。在 f64 中处理距离/光通量，禁止将 1e22 级距离平方直接放入 GPU f32。像素大小、透明度、近距淡出和五次方径向衰减按源规则核验，保留亮暗差异。

三维投影使用 Bevy 标准相机，不复制 Pioneer 特定的 +Y 前向投影语句。星空随相机方向变化，星体遮挡背景；缩放、聚焦和总览切换不让星空附着于行星或发生深度穿插。实际相机科学位置与源距离的组合由核心负责，不由插件产生第二套相机。

## 方案与职责

采用 **TS 解码 + 通用批量星空 SDK + Bevy 合批显示**。备选一是 Rust 直接解析 NASA 二进制，会把领域格式耦合进核心；备选二是烘焙背景贴图，会丢掉逐点位置、色彩和亮度信息。两者都不作为本次实现方向。

- 服务器：仅白名单七个文件，同源受控入口；核验固定长度与 SHA256，拒绝重定向及未知路径。约 1 MiB 的源文件缓存独立于 WASM，源变更须重新审查。
- TS 数据插件：严格解析和坐标标准化，以宿主登记的层 ID 与来源发布整层批量数据。不能直接访问 Bevy World、材质或内部相机。
- SDK：在现有 scene.visual 权限下新增通用背景点层接口，限定来源、有限数值、字段长度和预算；每个位置分量绝对值不超过 1e30 km，避免显示转换溢出；每会话最多八层、合计五万点。该接口不创建四万个科学对象，不挤占 4096 点轨迹预算；Rust 再检查权限及归属。
- Bevy：每层合批的相机朝向四边形及受控星点着色器，复用 Bevy Mesh/Material 和渲染能力；禁止一星一个实体或一星一个 draw call。背景不写入天体深度、不参与选择，不引入第二个三维引擎。
- 宿主：进入工作区即触发星空需求，优先亮星层，再有界并发补齐其余六层，不阻塞原十天体初始化；层成功即可显示。增加独立星空图层开关及加载/失败/重试状态，不将星空错误混为行星数据不可用。

关闭星空取消未完成请求并清理当前会话表示；重新开启可复用已核验的有限缓存。快速切换目标不重复下载同一星空；退出和重入不能复活旧层或重复累积 GPU 资源。插件停用释放所属全部层。

## 验收

1. 七个实际文件全部严格解析，记录总数、SHA256、首尾及字段范围可复核；不只解析最亮一层。
2. 单元测试覆盖长度、端序、非法计数、NaN/Infinity、黑色、零位置、四元数顺序、轴向、颜色及源亮度计算；543 条源不一致只记录，不擅改。
3. SDK/Rust/真实 WASM 回归覆盖权限、层归属、五万点预算、原子替换、清除和停用。未知文件不能成为任意网络代理。
4. 实际 GPU 检查总览、行星近景、环绕、缩放、前后遮挡、星空开关、失败重试、快速退出和重入；核对真实点数/批次，验证不会一星一个实体。
5. 运行本迭代全部适用检查及现有场景回归，记录 WASM 代码增量与独立数据传输，不能把数据文件计入核心；更新技能书、版本、CHANGELOG，提交推送并用 gh 跟踪对应 CI。

本次不同时加入星座线、星名标签、全天贴图、银河体积、星际导航或真实自行传播。七份点表均完整接入后，再按平台总体规划独立扩展。
