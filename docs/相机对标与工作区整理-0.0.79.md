## 银河盘资源与科学边界

原图：<https://eyes.nasa.gov/assets/static/sprites/milky_way.png>。下载至 `web/public/assets/sprites/milky_way.png`，1024×1024、433457 字节；SHA256 与获取时间见本目录 evidence/scene-cleanup-0.0.79/milky-way-source.json。资源独立存放，不嵌入 WASM，不在初始化主动加载。

本地参考 `solarsystem/eyes/src/engine/core/Unidentified695.js`、`VisibleInterval.js`、`components/SpriteComponent.js`：银河盘为非 billboard、双面透明四边形，大小 1.2e18 × 1.2e18 km。北银极 RA=192.85948120833°、Dec=27.12825119444°；银心方向 RA=266.40499625°、Dec=-28.93617241667°。太阳银心距为 2.46237071e17 km。

显示区间的 z-distance 是相机在银河盘局部坐标中的绝对 z（离盘面的高度），并非相机到银心的距离。minimum=1.2e16 km、fadeBlur=0.5，对应高度 6e15 至 1.2e16 km 渐显。不能用外部银河盘替换太阳系内部银河全景，也不能把银心直接替换现有日心科学原点。

本批完成下载和接入约束核查；银河盘实际显示需要独立环境资产契约与日心到银心的显示变换，当前尚未实现，不能宣称缩远已进入银河盘。

## 验收

200个同锚点标签连续60帧均保留，锚点不漂移；离屏标签仍不强制塞回画面。设置五类均可访问，现有调参、图层、来源、缓存、相机和性能诊断不丢失。主画面不显示原始 TDB、缓存统计、资源 SHA、性能 JSON 或调参面板。加载失败保留简洁提示并可进入设置查看详情。

## 可复核的控制链路清单

`evidence/scene-cleanup-0.0.79/nasa-camera-inventory.json` 记录10个源文件的 SHA256、行数及198个类方法名称/起始行。此为覆盖索引，不把 getter/setter 数量当作198项已对齐功能。

NASA ZoomController 每帧 `zoomFactor=2^(offset*0.05*modifier)`，modifier 在 x 键为0.05、Shift为5；W/S 同样驱动缩放。平滑值 `clamp(lerp(factor, previous,0.8),0.8,1.25)`，误差小于1e-7归1；乘到离地高度而非实体中心距，触及上下限立即清除残余倍率。OrbitController 拖动灵敏度0.01、平滑0.8，并乘 `min(1,FOV弧度)`，在低高度进一步减速。CameraManager 的按钮单击指数0.3、按住指数0.1是另一输入入口，不能拿一个“惯性常数”替代全部输入语义。

当前 `core/src/renderer.rs::apply_orbit_zoom` 共享离地高度公式，但最终中心距离仍统一 clamp(1e-8,1e12)；`camera_motion.rs` 为按时间积分的阻尼，不能假定与 NASA 每帧平滑0.8数值等价。需在30/60fps、横竖屏、近表面/卫星/行星系统/太阳系/银河范围分别测试输入曲线，不能直接照搬帧相关常数而引入帧率差异。

NASA 的场景相机建立在参考父体、受控姿态轴、位置和渲染相对坐标上。我们的 `OrbitView`、`DisplaySettings`、控制命令、TS SceneGesture/TouchCamera/ZoomButtonGesture 分处不同层；后续修改应建立共同输入动作和过渡状态契约，避免选择动画、原生鼠标、按钮和 TS 触摸分别覆盖同一镜头。

建议验收矩阵：地球/月球/LRO/ISS/MRO/Psyche/木星系统/太阳系总览；单击选择后立即滚轮、连续切换、正反高倍率、窗口失焦、取消加载、x/Shift与W/S、长按按钮、横竖屏和碰撞边界。银河盘另外核验太阳偏移、银极朝向、双面和盘面高度渐显。上述未执行的条目保持待验收，不能以编译成功替代。
