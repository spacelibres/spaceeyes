# SPACEEYES 来源与许可台账

版本：0.0.1｜状态：项目自有内容MIT已确认；外部来源逐项核验

| 来源 | 当前证据 | 许可/处理决定 |
|---|---|---|
| solarsystem自研TS模块 | src/lib/dynamo、src/solar/domain等 | 仓库根MIT声明不自动证明每一段恢复/改编内容均可复用；逐文件审查后再迁移 |
| 恢复的NASA Eyes应用源码 | solarsystem/eyes/src及相关研究 | 先核查版权与再分发授权；不直接复制到spaceeyes |
| NASA DYN/图像/模型数据 | 远程资源、测试夹具、镜像 | 核查各资源许可、署名、再分发、缓存和商标限制；未核实不得批量发布 |
| Three.js/Next.js及其他依赖 | package.json、lockfile、第三方许可 | 逐项确认版本、许可、漏洞与署名义务 |
| SpaceEyes自有Rust/Proto/脚本/文档及后续自研SDK | 当前独立实现，根LICENSE、Cargo元数据、源文件SPDX声明 | 用户确认统一MIT；Resources与其它模块相同，不另设许可 |

**注意**：NASA数据来源不等于NASA认可；不得把参考仓库的整体MIT声明当成对NASA恢复源码和素材的独立授权。审查完成前，迁移采用行为规格、测试及自主实现，不直接复制受限资产。

> 2026-10-27版本核查：当前文档版本同步至统一开发版本0.0.1；历史规划/审计内容与许可待核实状态保持不变，不构成新的设计批准或资产授权。

## 2026-10-27 MIT决定与边界
项目自有内容采用MIT，版权声明为“2026 SPACEEYES contributors”；所有12个Cargo包继承workspace MIT元数据，项目自有源文件采用MIT SPDX标识。现有第三方Rust依赖通过Cargo.lock解析并使用，未复制进项目源码；其许可仍以各上游包为准，不能将所有依赖概括为“都改成MIT”。后续引入NASA资产或参考库源码时保留独立来源核验。当前许可决定不自动改变GitHub仓库公开/私有设置，也不等于对第三方资产的再许可授权。
