Goal：一轮完成轻惯性、真实银河/星光/太阳效果及稳定标签可见性。

Architecture：Rust/Bevy 相机、投影、遮挡及合批显示；TS 数据/资源插件按受控 SDK 声明环境和发光效果；源图及 shader 外置。NASA 银河使用已下载核验的4K EXR，不依赖不可用的 Eyes JPG。
