# ISS 高倍率播放与 NASA 标签对齐修复

复现使用用户提供的 ISS 链接：TDB 846686627.4034829，480 倍播放，Nearby、自然光、45 度视场，所有对象与轨道图层开启。参考代码位于 `C:/Users/stone/Documents/solarsystem/eyes`。

## 全局审查发现

1. RAF 用任意场景对象的覆盖到期触发全场景暂停和重载。无关航天器过期会把 ISS 的有效播放一起拖停。
2. 每次维护会同步重建全部过期轨迹，已复现单帧重建 9 条路径；选中目标另用 2048 点，历史拖尾的中间质量核验进一步放大工作量。
3. 已被移除的对象仍进入轨迹维护，可能抛出覆盖或 UnknownObject 错误，通用异常处理随即暂停播放。
4. 关键参考对象未完全进入优先加载集合，跨段可能丢失跟随模式；后台对象重新加载后，如果不恢复显示配置，会丢失模型和标签。
5. 标签每帧搜索避让槽位会跳离对象，远处对象没有可辨识显示时仍保留标记、文字和点击区域。

## 修复

科学时间与非关键对象加载解耦。只有选中目标、跟随参考、父体与姿态依赖进入前台覆盖门槛；总览只以太阳原点为关键对象。其他对象失效时隐藏并在后台逐对象加载，不回退科学时间或改变播放。失败重试有每对象一秒冷却；请求及恢复都受生命周期和选择修订约束。

真正关键数据段到期时，先加载该依赖闭包，关联对象随后补齐；保持最新播放意图和跟随参考。不在无数据时伪造轨道或外推。后台恢复每帧最多一个对象，恢复模型、标签和轨迹，避免整场景重复配置。

轨迹维护每 50 毫秒最多一条，选中目标每 100 毫秒获得优先机会，其余公平轮转；同帧恢复对象时不另加轨迹维护。选中目标输入上限从 2048 降为 256，原有曲率检查继续执行；完整解析轨道的 360 段显示不受此影响。已失效对象从维护集合移除。TS 发布在单次、同一精确科学时刻内复用父体位置，调用结束立即释放缓存，不跨时刻保留近似状态。

## 标签按最新要求对齐

本地 `LabelManager-563.js` 与 `LabelQuadtree.js` 使用对象锚点、类别权重、距离和名称处理遮挡；本轮取消原有 52 槽移位策略。标签固定跟随对象，重叠时隐藏低优先级名称；不再为了塞下全部名字搬动标签。类别优先级采用太阳 100、行星 50、航天器 30、天然卫星 25，随后按科学距离和名称稳定排序。

对象显示必须就绪、在视口内且未被遮挡；模型按实际取景半径参与可辨识尺度判断。航天器亚像素显示采用 1.2 像素出现、0.8 像素消失的滞回，标记、标签及点击区域共用该判断，避免隐形点击点和临界闪烁。这个像素策略是本平台明确的显示规则，不冒称 NASA 源码中的同名距离阈值。选中和近景名称隐藏继续保留。临时隐藏仍复用原标签实体，真正删除才清理。

## 验证边界

集中回归覆盖 480 倍时间推进、每帧路径维护上限、无关对象失败/缺覆盖的重试、总览独立推进、选中及跟随参考跨段、对象恢复、固定标签锚点、优先级、视口与像素滞回。实际浏览器复现、真实数据段边界及测量结果见 `docs/evidence/iss-playback-labels-0.0.51/`。
