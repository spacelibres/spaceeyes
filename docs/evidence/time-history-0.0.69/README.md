# 时间与数据一致性第一批

基线1b5d19002；核心0.0.54保持不变，SDK0.0.43、网页0.0.69。只修改TS历史缓存策略，不改相机、材质、标签和轨迹几何。

## 根因与修复

准备和采样原来都要求epoch不小于缓存锚点，倒播立即回到本地较短覆盖并重建历史。原正播复用还可能截短预览右端。新增统一匹配入口，要求相同对象、当前父体、显式长度策略及abs(t−t0)≤D/32。准备范围改为[t0−33D/32,t0+3D/32]，包含该时间带中任意时刻的完整显示区间[t−D,t+D/16]。

准备范围不等于保证数据处处存在。源缺口仍显式断线、当前历史点不可用仍回退主源；32段/200000记录、共享4请求槽和取消/晚到结果保护均保留。自动长度策略本身未在本批改动。

主源已覆盖名义显示窗口时继续跳过私有历史准备；余量只用于确实需要的私有历史，避免额外请求。此边界增加独立断言并先复现失败再修复，最终静态复审无明确缺陷。
