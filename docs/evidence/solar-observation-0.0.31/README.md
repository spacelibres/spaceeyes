日期：2026-10-31；核心0.0.25 / SDK0.0.24 / 网页0.0.31，codex/bevy-planning。

## 范围与来源

设计：docs/太阳观测约束与三维重建设计.md。Parenti 2014 的日珥尺寸、流速及热力学范围用于约束；Labrosse 2010 的形式解用于常量源函数透射近似。Mackay 2010 的局部磁拓扑作为几何参考。没有求解 MHD/NLTE、真实磁场或谱线响应。

## 自动验证

命令：`pwsh -NoProfile -File tools/check-core.ps1 -Renderer -ReleaseWasm -Workspace -NativeCamera -Samples validation/.cache -JunoAssets -SolarAssets`。

完整结果见 checks.log：Rust基础、fmt、clippy，TS/资源验证，真实WASM SDK集成，release WASM，网页测试/typecheck/Next构建、62个固定表面/环资源，原生渲染54项。测试包含严格旧58项迁移、74项边界、所有权与撤销、SI换算与q电离分数、透射极限及顺序、几何单位/弧长/12-24-48细分误差、独立管束、近远创建回收与共享资产保留。

## 实际 GPU 验证

IAB，ANGLE Intel Arc B390 / D3D11 / WebGL2。可见视口1920×1080，DPR1.5，canvas2880×1620。场景10个对象、银河与43878星点开启；另有用户原页面存在，不能将进程级GPU利用率当作单材质GPU时间。

- final.png：最终构建重载后的画面，gpu-logs.json记录最终捕获的两类错误均为空，最终重载未再捕获适配器INFO，适配器信息来自本轮前次初始化日志。
- near.png：橙红自发光表面、局部卷曲亮区、有界近表面日冕；未采用外部光照计算太阳明暗。
- 旋转后局部结构随球面改变投影，未使用面向相机的太阳表面片；近景三个外置shader均实际加载，无错误日志。
- paused-a/b.png：固定表面区域(700,350)-(1150,750)，180000像素无一变化；恢复moving.png后178683像素变化。动画独立于统一仿真时钟播放。
- off-settings.json/off.png：关闭全部后三个开关与coronaGain均为0，近景没有太阳表面/日冕残留；只保留对象标签。
- far.png：回到总览，细节距离门控；资源释放由真实App生命周期测试独立验证。
- 可见近景进程3D引擎短时采样52%、66%；较小视口采样19%。这些是系统瞬时利用率，不是材质耗时或稳定帧率保证，没有采集GPU timestamp或逐帧耗时。

## 仍有的差距

当前参考重建比照片简化：细密磁环、复杂暗纤维和真实活动区形态仍不足。活动区、动态噪声与源函数是有限程序化显示，非实测喷发；物理尺寸还乘明确显示倍率。没有验证WebXR/VR。聚焦30Hz/失焦5Hz是更新策略上限，不是实测FPS承诺。

资源仍按需从服务器加载，不嵌入WASM；新模式近日冕无旧12R积分循环，表面每像素4次噪声、4个活动区，日珥总顶点硬限50000。旧58项配置及未调参旧VisualSpec保持旧模式。
