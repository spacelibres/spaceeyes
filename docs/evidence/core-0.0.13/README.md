# 0.0.13 总览可见性与层次

针对总览只有明亮轨道、内侧标签挤在一起且天体无法辨识的问题，本批加入远景屏幕标记、发光天体暖色光晕、标签避让及焦点轨迹层次。科学位置、半径与有效轨迹样本保持原值。标记是屏幕空间辅助表示，不表示真实天体尺寸，也不提供场景内点击拾取。

标签优先保留焦点，无焦点时优先发光对象；尝试多个相邻位置，超出视口或没有空位时抑制标签。物理投影半径接近 3—6 像素时标记渐隐。外置字体和选中对象才触发表面加载的路径保留。

当前宿主照明以 ICRF 原点为中心近似聚焦光向，不依据插件的 emissive 设置授予其全局光照权限；关闭方向光阴影。本批没有增加通用光源 SDK，也没有实现逆平方辐照度或完整 NASA 光照模型。
