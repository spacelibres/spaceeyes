## 实际 GPU 与鼠标操作

1. 默认窄视口刷新并自动进入真实场景；`before-pick.png` 的 EARTH 标签处 (72,447) 用实际鼠标点击，选择变为地球，信息面板自动展开、表面状态 ready，见 `label-selected.png`。
2. 关闭面板，地球实际表面仍可观察，见 `earth-surface.png`。点击空白 (430,180) 保持地球选择且不展开面板；从 (200,350) 拖到 (260,380)，实际地理朝向改变，目标仍为地球，面板不误展开，见 `drag-no-selection.png`。
3. 点击球体非标签处 (190,350)，重新触发同一选择链，聚焦地球并展开面板。打开目录核对地球 `aria-pressed=true`，未建立单独的场景选择状态。
4. 临时设置 1280×720 验证归一化输入，返回总览并等待过渡；`desktop-overview.png` 中点击天王星远景标记 (596,324)，选中天王星、真实资源 ready，见 `marker-selected.png`。
5. 恢复默认视口，关闭面板后在当时可见球体 (375,430) 点击，仍命中天王星并重新聚焦，最终观察见 `uranus-surface.png`。测试结束未保留视口覆盖设置。

`resource-requests.json` 是本次浏览器观察到的请求清单：总览必要轨道数据和外置字体之外，姿态与表面请求只有已选择的地球、天王星；并非一次获取全部表面资源。自动测试另行确认空命中不发起重载、返回总览不被旧异步点选重新聚焦，以及退出后查询被拒绝。宿主流程测试替换了 GPU 命中候选，因此不能拿它替代上述真实投影点选证据。

## 实际边界

命中使用最近一次相机投影圆盘及避让后的标签估计矩形，深度按对象中心距离排序，远景提供至少 12 像素命中半径。它是当前球体场景的近似屏幕拾取，不是精确球面射线、模型三角形、土星环或任意遮挡配置的完整实现；极近景轮廓、复杂遮挡和全部输入设备仍需后续验证。

未宣称 NASA Eyes 同对象/同时间成对视觉或完整相机验收。视口变化后的自动取景、过渡节奏、LOD、大气、光照、科学精度与性能阈值仍待后续批次。金星/火星无效源数据继续明确报告。
