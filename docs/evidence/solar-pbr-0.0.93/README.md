# 逐对象太阳方向与PBR接线 0.0.93

采用既有A33设计的ExtendedMaterial方案，复用Bevy0.19.1的BRDF、贴图采样、环境反射、相机点补光和颜色后处理。通过曝光一致的贡献差额替换单盏无阴影方向光的太阳项，不复制完整PBR，也不增加天文点光或调整曝光。世界空间法线已由Bevy提供，因此使用f64科学位置相减后得到的世界显示方向，避免对象空间往返变换。

每对象/版本/源材质独立持有扩展材质，源AssetEvent同步异步贴图和材质变化，退出清理自有资产。环使用同一太阳采样。太阳和unlit模型保持原路径。透射材质明确保留原Bevy光照；本适配尚不支持太阳阴影、灯光贴图和lightmap排除项，不能宣称完整光照对齐。

before.log保留旧全局方向算法的两项失败。checks.log完整本地检查退出0，含167项原生渲染及其余Rust/TS/WASM/Clippy/发布构建/资源检查。独立代码审查无确认阻断项。
