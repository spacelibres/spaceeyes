## 实际浏览器

1. 刷新首页自动进入实际 Bevy 场景。画布为整个视口，默认不展开工具面板；`overview.png` 是返回总览并等待相机过渡后的画面。
2. 键盘打开探索天体，选择地球，目录收起、对象面板展开，焦点移入关闭按钮；实际表面加载为 ready，见 `earth-panel.png`。鼠标点击关闭对象信息后，面板收起，焦点返回对象与图层按钮。
3. 打开日期与跳转，跳转 TDB=0，显示 UTC `2000-01-01T11:58:55.816Z`。在跳转按钮上按 Escape，面板收起、焦点回到日期与跳转按钮。
4. 播放推进到 TDB=9.803 秒，暂停按钮恢复为播放，随后选择地球并返回总览。
5. 390×844 窄屏实测：document clientWidth/scrollWidth 均为 390；canvas 为 (0,0,390,844)，见 `narrow.png` 和 `layout.json`。时间浮层没有被数据错误提示遮住，所有跳转按钮可见。验证后恢复默认视口；桌面布局尺寸同样记入 JSON。

复验过程中发现并修正顶部文字重叠、面板关闭焦点丢失、窄屏时间栏过度换行，以及错误提示压住日期浮层按钮。最后的集中检查与截图均基于修正后版本。

## 尚未验收

NASA 在线页面两次采集超时，本次未获得新的同对象、同时间成对截图。NASA 官方介绍 https://science.nasa.gov/eyes/ 作为沉浸式三维目标参考，不替代交互实测。

场景内点选、完整相机过渡与尺寸变化取景对照、表面 LOD、大气和光照效果、科学精度及性能阈值仍待后续迭代。窄屏证据仅证明画布与工具布局，不代表所有天体在所有纵横比都已完成取景验收。金星/火星源数据仍报告不可用，不伪造。
