# 太阳正面等离子体遮挡修正 0.0.25

网页0.0.25，Rust核心0.0.19与SDK0.0.20保持不变。完整集中检查退出0，原生渲染库39项通过；见checks.log。

根因：体积代理只绘制背面，背面深度位于太阳实体之后，默认深度测试把太阳圆面前本应可见的积分也挡掉。修复：片元输出体积入口深度；积分在太阳单位球首次相交处截断，确保不是把背面画到正面。相机位于体积内时入口使用reverse-Z近端，代码支持该分支，但本轮未完成其独立实际GPU验收。

实际GPU近景无shader ERROR或error日志，见browser-errors.json。镜头固定且科学播放暂停，front-a.png与front-b.png对比：圆面内部半径210像素区域共138505像素，84390像素RGB差值和大于12，最大差值和96；见front-comparison.json。证据确认正面等离子体在变化，不能将此称为光球纹理自身物理演化。

限制：显式入口深度仍不是任意多物体的逐采样深度合成，位于体积内部的航天器等需要后续完整场景深度截断。太阳实体背面遮挡采用解析球面；未扩展为MHD或无贴图光球。
