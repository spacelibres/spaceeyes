# 掠视轨迹弧线修正（网页0.0.88 / SDK0.0.50）

## 原因及范围

旧采样器使用相机到端点及九个探测点的最小距离衡量弦误差。相机贴近这些点之间的线段时，该距离可能远大于真正的近轨距离，误差评分不足，斜视放大后仍出现明显折角。本次改为相机到整个有限线段的最近距离，直接细分并重新求值真实DYN，不用样条伪造轨道。

NASA本地参考为`eyes/src/engine/components/TrailComponent.js`的真实源求值及受限分帧采样思路；本次补足观察空间约束，不改变任务阶段、父体、时间、拖尾、标签或相机行为。保留512点上限、每次源求值让出、原队列和缺口语义。核心0.0.63不变。上次输入排查临时日志已移除；鼠标响应问题未在本批声称解决。

## 回归与真实源

真实STEREO A：TDB846620500，分别在当前位置、前一小时、前一天的位置Z方向偏移1km观察；213/206/207点，最大误差代理均低于0.000492，历史范围816782358.6181641—846649610.3818359，未新增断点。脚本measure-stereo.ts和source-audit.jsonl保留复现结果。历史补取返回false、当前历元采样点与当前源位置一致，排除了此场景的历史/当前状态错位假设。

## 边界

固定点数预算耗尽、局部极窄且九个探测点均未捕获的源曲率仍是既有边界。原截图没有可恢复的鼠标相机姿态，不能声称逐像素复现；本次不代表所有轨迹或所有NASA交互已验收。GPU计时、显存和整帧分位耗时未测。远端CI提交后单独核验。
