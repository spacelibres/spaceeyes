# 0.0.102 滚轮缩放验证

本地 NASA Eyes 反编译参考中的 Input.js 将像素滚轮输入乘以 0.1，ZoomController.js 默认灵敏度为 0.05，以 2 的幂改变相机离地高度。本次将浏览器像素输入转换为 `deltaY × 0.005 × ln(2)`，再使用既有的对数距离缩放；单次仍受 SDK 的 ±1 输入范围限制。NASA 自身按帧平滑并限制单帧倍率，因此此映射不代表惯性曲线已完全一致。

实际浏览器使用 Psyche、TDB 847409579.0087576、暂停、FOV 45、原画质；滚轮每次 120 像素，四次拉远后四次反向：

| 场景 | 起始距离 | 四次拉远 | 四次反向后 |
| --- | ---: | ---: | ---: |
| Psyche 修改前 | 0.143224 km | 0.231461 km（1.62 倍） | 0.143224 km |
| Psyche 修改后 | 0.143224 km | 0.755941 km（5.28 倍） | 0.143224 km |
| 地球近景修改后 | 36539.883 km | 165572.950 km（4.53 倍） | 36539.888 km |

两种天体场景均实际触发浏览器滚轮，等待惯性基本消退后读取相机位置；地球距离变化包含地表半径的影响。单项滚轮测试、网页141项测试、类型检查和生产构建通过。完整项目检查以 GitHub CI 指定的 Rust 1.96 通过，包含168项原生渲染测试。

NASA 在线应用本次未能打开，未做真实页面手感对比；触控板、高倍率远景、惯性曲线、GPU时间和显存尚未验收。
