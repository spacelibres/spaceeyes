# 太阳系总览与相机交互

核心0.0.28 / 网页0.0.34，2026-10-31，codex/bevy-planning。

## 规则

太阳系总览，以及远景太阳焦点只显示SUN名称；近景选择隐藏名称的规则继续生效。其他行星的对象本身、目录和轨道不删除。局部行星视图仍按已有遮挡/碰撞/距离规则显示其系统标签。

相机按科学坐标检查整段移动：所有已有科学球体均阻挡，包括非中心行星。先处理已有重叠，再扫掠到最近接触点，并在接触处取有限切向步长绕行；快速滚轮和聚焦过渡不能从球体另一侧穿出。浮动原点切换前后保留相机科学位置，碰撞间隙包括显示f32投影的数值余量；不改天体科学半径。贴图mip级别不等于可下钻地形LOD。平台当前没有地形加载就绪及高度表面的下钻契约，故不开放穿透例外。

旋转松手惯性上限0.6秒，衰减半周期0.14秒，最大余转小于10度；缩放惯性不改。新按下、失焦和交互重置仍清除残留，VR头显姿态不使用此鼠标滤波。

## 验证

完整命令：`pwsh -NoProfile -File tools/check-core.ps1 -Renderer -ReleaseWasm -Workspace -NativeCamera -Samples validation/.cache -JunoAssets -SolarAssets`；checks.log记录完整检查通过，原生62项。覆盖整段穿越、擦边、初始在内部、最近球体、反复正对穿越后的绕行到达、f64重基准，以及实际App中非中心行星与原点/尺度切换。惯性验证不同帧切分一致、0.2秒后仍有余转、0.6秒后停止、失焦清除。

GPU验证与截图在同目录；截图不能替代数值碰撞断言，也不证明任意地形/复杂模型的精确网格碰撞。本轮采用科学球体包络，不是模型三角面碰撞。


实际画布：总览截图在用户当前524×1724及1016×940视口下只见SUN名称，其他天体点与轨道仍在。松手截图release-a/b的背景区域(30,230)-(490,650)共193200像素，其中191364像素变化；统一科学时钟保持暂停。该截图对比展示松手后的继续移动，持续时间与上限由确定性数值测试量化。贴图地球能正常绘制，浏览器滚轮过程中存在用户同步交互，故不以该操作序列替代穿透/重基准的App断言。gpu-logs.json捕获两类错误为空。

碰撞采用当前历元科学球体，不是复杂模型三角面、地形高度或时间跳变中天体运动的物理碰撞求解。未来下钻必须以可用地形数据和表面约束替换碰撞边界，不能仅因存在多级贴图就关闭碰撞。
