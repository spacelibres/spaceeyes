# Parker太阳风数值接入 0.0.24

SDK0.0.20、网页0.0.24；Rust核心保持0.0.19，数值模型独立TS，资源不进入WASM。完整集中检查退出0，新增2项Parker测试通过，原生渲染库39项通过，见checks.log。GPU近景运行包含实际查表的WGSL，无error或Bevy ERROR，见browser-errors.json与solar-wind.png。

模型：纯完全电离氢、电子与质子同温、稳态等温球对称Parker跨声速解。IAU nominal GM、R与NIST常数见validation/solar-wind-model.json及其sources。1.5MK和1AU电子密度5cm^-3是示例边界假设，不是当前日期观测。下边界R作为日冕基部的几何近似，不将光球假设为150万K。

结果：cs=157363.271562m/s，rc/R=3.85170381，基部u=4723.882905m/s，基部ne=3.0737855e13m^-3，1AU u=628052.371463m/s、ne=5e6m^-3。完整257点SI表见model-result.json（含飞行时间）；隐式方程残差在101测试点小于1e-10，质量通量相对偏差小于1e-12。这些是数值求解一致性检查，不是对太阳实测精度认证。

WGSL使用1..2.8R的32点log密度/飞行时间插值；飞行时间采用梯形数值积分，尚无独立误差认证。模型半径695700km与DYN对象695500km分别保留，仅按r/R显示归一化。色调用相对ne²包络的四次方根增强，未引入CHIANTI波段响应或绝对光度。时间压缩为3600乘flowSpeed个模型秒/显示秒，当前flowSpeed=0.15时为540倍；不把科学TDB播放速度当作扰动真实传播速度。

限制：现有根部火舌、日珥和表面仍包含视觉模块与NASA表面纹理；Parker只能提供球对称背景外流，不能求解真实磁场、日珥爆发、CME、光球对流或核聚变。因此不是整颗太阳真实MHD仿真，也没有完成用户长期要求的无照片表面。噪声只作扰动显示，不能解释为测得的磁结构。
