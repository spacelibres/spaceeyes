# 0.0.104 三维场景优先初始化

核心0.0.70、网页0.0.104；SDK0.0.57保持。先注册核心和插件、启动 Bevy，并等待首批实际渲染帧及渲染管线稳定，再发起星空、银河和太阳系数据请求。场景可操作前继续等待初始天体显示资源和最终渲染帧，避免重现启动后鼠标无响应。取消和着色器失败仍可终止等待。

太阳系全景首次加载八大行星表面；六面图转换仍采用原有2048×1024、同一逐像素算法和完整资源。此前每帧处理16行、最多一个行星；现在每次仍以16行为基本工作单位，在本帧2ms预算内最多处理64行，慢设备可在首个工作单位后停止，结果完成后才发布。原有逐像素一致性测试和新增预算中断、恢复测试通过。

同一机器、太阳系全景、TDB 847420778.1826147、1×、相同视口和画质的浏览器单次对比：0.0.103 完成约40.99秒，0.0.104 完成约19.45秒；候选版约1.65秒进入数据加载阶段，说明空三维场景先完成初始化。长任务总时长约20.4秒降至11.7秒，最长单次约7.79秒降至3.56秒。不同冷缓存和系统负载会影响单次结果，不视为保证的倍数或完整 GPU 基准。

另一次相同全景着色器链接采样中，约9万字符以上的 PBR 管线由5个变为3个；实测截图中八大行星资源8/8就绪、恒星层7/7，进入后滚轮和拖动使相机位置变化。浏览器错误控制台为0；截图见 overview.png。拖动与滚轮的一组操作及两帧等待约104ms，运行后 CPU p50/p95约6.7/10.3ms、画质比例1，目标帧率30。候选版 JS 堆约40.9MB，基线 JS 堆、GPU执行时间、显存及进程RSS未取得，不能由此推断两版总内存或GPU性能；完整指标见 metrics.json。

完整 Rust/TS/WASM、Clippy、资源、生产构建、144项网页、79项集成和169项原生渲染测试通过，见 checks.txt。真实 NASA Eyes 在线手感及全部视角未在本次完成对比；着色器冷编译仍有约3.56秒长任务，需继续优化，结果不表示启动问题全部消除。提交后通过 gh 跟踪远端 CI。
