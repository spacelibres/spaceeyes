# Dione至太阳系缩放交接

## 用户确认与物理语义

固定复现场景：`#/dione?tdb=846871891.7553412&rate=1&play=0&mode=nearby&view=orbit&light=shadow&fov=45&labels=1&orbits=1&trails=1&moons=1&craft=1`。检查截图时暂停时间以控制变量。

用户确认“保留NASA方式，改善整体过渡”。本地NASA源码controllers/ZoomController.js的__update以缩放倍率改变相机到地面高度，managers/CameraManager.js的zoom改变相机距离；不是将各系统单独缩放，也不是改变FOV使远近物体等倍变大。真实透视下，近处土星系统变化显著而远处行星短程内变化很小是正常现象。

本项目core/src/runtime.rs的sync_scene和renderer.rs的draw_annotations对模型及轨道均使用同一origin_km与units_per_km。此次不修改科学位置、资源尺寸、轨道、标签、光照或星空。

## 已定位的错误

当focused distance超过原有自动返回阈值，旧实现清除焦点后触发overview的fit-to-all；它按全部已载入对象范围重新取景，同时将相对卫星的距离当作绕太阳的距离，并重置惯性。结果不是沿用户的同一次缩放继续移动，而是附加一次大幅取景飞行。新回归在第一帧测到旧实现额外移动59,710,587.54km，因而失败。

实机还发现，朝太阳方向拉远时，原来的“最远目录对象范围一半”阈值位于太阳碰撞点之后。仅修正fit-to-all仍会把碰撞拦截后的太阳附近眼位交给总览。补充包含真实相机输入与碰撞系统的Sun-facing Dione夹具，旧阈值下最低日心距离717,468.53km，无法通过应在碰撞前交接的断言。

## 修正

- 自动交接记录当前相机的真实全局位置，换算AU距离并清除原局部地面半径；在下一次原生输入前完成单位交接，保留未结束的滚轮惯性。
- 自动交接阈值取原全局阈值与当前向外路线最近实体球面入射距离一半的较小值。后一项是本项目的导航安全裕量，不是假称NASA原码阈值。仅有向外滚轮/SDK缩放意图时生效，固定距离的环绕不会自动丢焦点。碰撞系统仍运行。
- 仅自动交接绕过fit-to-all，显式进入总览的取景规则保留。自动转向用1.5秒混合，平移始终直接跟随本帧缩放；继续滚动不会打断转向，主动环绕可以接管。常规显式焦点切换继续原0.35秒策略。
- 宿主在自动返回总览时保留已经就绪的原局部对象，并补充太阳系对象；后续刷新也保留该上下文。显式选择其它目标或主动进入总览会清理此上下文。已有场景256对象硬预算不变，没有以性能名义删掉卫星。
- 总览继续使用原全局Ry(yaw)*Rx(pitch)，用全局眼位求yaw/pitch，避免把旧相机的倾斜轴带入新总览。
- 改变旋转中心可能使合法相机位置映射到原1.5弧度俯仰范围以外；保留该初始角度，禁止继续向外、允许渐进向内，而非零输入时突然截断。

## 验证与边界

命令：`pwsh -NoProfile -File tools/check-core.ps1 -Renderer -ReleaseWasm -Workspace -NativeCamera -Samples validation/.cache -JunoAssets -SolarAssets`，退出0。Rust基础、TS平台/网页/宿主、WASM集成、Clippy、类型检查、发布WASM、Next构建、157项原生渲染测试及离线资源核验通过，完整记录checks.log。

原生回归包含：自动交接30帧中全局眼位误差低于5000km（此为十亿km级场景f32显示换算的测试容差，不是科学位置精度承诺）；FOV保持45°；AU地面半径为0；惯性未清除；水平环绕保持全局纬度；极区不会因零俯仰输入跳回；既有显式总览太阳居中及相机输入/碰撞测试保留。独立审查曾发现倾斜环绕轴问题，新增红灯断言后修正，复审无其它阻断项。

新增实际向太阳拉远的输入→焦点更新→碰撞夹具，先确认镜头确实朝太阳方向，再执行缩放，断言交接发生、最近日心距离仍大于2.5亿km；固定距离转向父体仍保留Dione焦点。宿主集成回归确认从月球自动拉远后LRO仍存在，Voyager仍补入，时间播放不暂停；原清理策略会产生UnknownObject，保留上下文后通过。既有宽距返回测试补充真实camera_zoom意图，而不是只直接改内部距离。

浏览器证据固定上述目标、时刻及45°FOV，连续约100次减号：dione-before.png为旧构建，dione-local.png为修正后的局部阶段，dione-after.png为自动交接后的整体阶段，solar-orbit.png为随后反向缩放及环绕。最终回归一次输入自动化在第38步超时，读取当前画面后继续，不能当作精确像素/输入时序对比。控制台error与ERROR均为空；临时采样日志已移除，没有新增调试界面。键盘输入和硬件滚轮不是相同事件源，硬件滚轮的浏览器全链路未单独量测；惯性保护有原生回归。
