# DYN 本地优先验证（网页 0.0.111）

- 只读旧镜像配置为本机 `solarsystem/dynamo-cache/files`；增量原始文件写入 SpaceEyes 自有持久目录，保存 URL、字节数、SHA-256 和获取时间。旧镜像未建立全量逐文件可信散列，读到的原始数据仍经过既有 DYN 解码、时间覆盖和版本审查；本次不声称全库完成完整性验收。
- 强制 `SPACEEYES_NASA_DYN_OFFLINE=1` 并以抛错的 fetch 禁止网络，TDB `847420778.1826147` 的地球、金星、火星、月球、木星、土星、ISS、LRO、BioSentinel、Juice、Europa Clipper 均可读取并解码，网络调用为 0。生产服务器同模式下对应本地 API 均返回 HTTP 200；首次请求 42ms，其他代表请求 5–10ms，单次本机结果不代表全场景性能。
- 1949-12-31、2000-01-01、2049-12-31 对上述七个代表天体/航天器分别检查位置及姿态。存在任务时间不覆盖及本地缺失，严格离线下明确失败；三个日期分别 10/14、11/14、10/14 成功，不能把来源缺口冒充已覆盖。
- 真实 GPU 地球近景在 DYN 严格离线模式下显示天体及卫星；测试后恢复正常本地优先模式。静态资源、银河、轨迹画质与对象配置未缩减。本次未完成全目录/全部分段和 1949—2049 连续时间审计，也未量化 GPU耗时、显存和总内存。
