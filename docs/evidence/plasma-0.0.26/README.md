# 三维外流体积与空间层次 0.0.26

核心0.0.20、SDK0.0.21、网页0.0.26。完整集中检查退出0，原生渲染库39项、Parker/三维输运专项3项通过，见checks.log。

根因：2.8R显示包围体小于通常4R的近景相机距离，物质不可能到达镜头；方向坐标的时间平移、纯加法合成又削弱纵深。本次扩大显示体积到12R，采用随径向Parker飞行时间输运的三维笛卡尔物质标签；摄像机不进入密度场定义。三轴及斜向测试验证沿特征线标签一致、前半球物质靠近摄像机和透视尺寸增长。

48步前到后积分、预乘透射合成，保留太阳首次相交截断、显式入口深度；64点对数半径查表覆盖1..12R并用常数时间索引。当前消光与稀薄团块亮度增强属于显示参数，不是CHIANTI校准辐射或MHD磁场结果。

实际GPU：最初高开销版本截图超时；优化为无sin哈希，火舌仅近表面采样、减少多重噪声后，截图及侧向环绕正常，未见error级或Bevy ERROR。截图inside-a.png、inside-b.png为固定镜头且科学时间暂停；外场368330像素中318423像素RGB差值和大于12（animation-comparison.json）。orbit.png为侧向环绕。该证据证明动画和空间观察运行，不是逐团块实测速度、主观扑面感或VR帧率认证。

限制：扰动是周期性可视化密度场，Parker只约束球对称背景，不能把整个扰动场声称为严格MHD守恒解。12R是显示边界，科学Parker数据仍到1AU。太阳光球仍有NASA纹理，日珥仍为显示弧束。场景内部任意物体逐采样深度合成尚未完整实现。
