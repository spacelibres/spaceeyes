# 0.0.98 安全增量采样与发布开销

版本：网页0.0.98、SDK0.0.55、核心0.0.68。用户起始时刻846972583.005967，NASA Eyes持续拖尾语义，保持科学源、可见拖尾及原画质。

## 修正

Worker曾在每次源扩展时清空已经算好的样本。现在只有相同布局/参数、父体/控制器、完全相同的相邻插值节点区间才能复用；缺口、越界和变化的姿态仍失效。先关闭受影响的旧迭代器，再更新源和修剪缓存，以相同任务token继续；旧结果独立版本校验，不准回写旧缓存。

可见区现在继承已经计算的前方真实点，三个区间容器独立，曲率证书要求同观察者且无已知失败探测。动态八次源扩展保持Worker与标准主线程输出完全一致，源调用少于冷启动三分之一；每帧推进约20%轨道的转移回归保留原端点、点数和误差约束。

隐藏缓冲按方向分配.25/1.75周期和相应点预算：可见N、总3N、单路径4096和会话49152保持。小于32点/default方向0仍对称。反向桥接只有实际四分之一周期；不伪报更大覆盖。刷新按已有实测提前量调度。Worker改消息任务唤醒，仍为原15ms量子及单一待唤醒回调。

高频带时刻JSON对象直接解析为原Timed结构，避免Serde untagged先缓冲全部点。所有非对象仍用旧解析器，包含其原本接受的位置参数数组；权限、容量、字段/样式/时刻校验和提交顺序不变。优化版真实WASM的18项回归通过。同硬件、同60路径/512点/每轮600次发布，七轮中位耗时：直接绑定121.4→91.7ms，完整SDK248.1→200.7ms；原始结果在metrics.json。这是该固定微基准，不代表整帧同比提升。
