# 资源验证实验

这是从资源分析进入编码的第一步：用独立、离线的 TypeScript 工具验证样本结构，不接入旧实现，不作为正式插件 SDK 或 Rust 核心。

需要 Node.js 24.15.0 或更新版本。运行时无第三方依赖，版本保持 0.0.1。

## 复现

在仓库根目录运行：

```powershell
node --test validation/tests/*.test.ts
node validation/verify.ts --samples validation/.cache --output validation/results/latest.json
```

样本目录需要包含 `manifest.json` 中列出的文件。该清单固定来源 URL、文件名、字节数和 SHA-256；可按 source 下载并保存为 file。工具不会自动下载或更新散列。上游文件变化时先调查差异，不能为了通过测试直接替换散列。

`.cache/` 和 `results/` 已忽略，第三方样本不提交进项目。任一检查失败退出码为 1，全部通过为 0。报告逐项列出来源、散列和检查范围。

## 验证边界

| 样本 | 本次检查 | 尚未验证 |
| --- | --- | --- |
| Juno glTF 和 BIN | 固定身份、缓冲区边界、22 个 POSITION accessor 的 34637 个顶点及 min/max | 索引拓扑、纹理内容、材质、模型变换和 Bevy 加载 |
| 星系点数据 | 1211 条记录、23 字节步长、浮点字段有限性 | 科学单位、坐标变换与绘制 |
| 地球 KTX2 | 容器头、5 个 mip 的区间、BasisLZ 标识 | 完整格式合规、转码和 GPU 显示 |
| 三份 DYN | 头、记录长度、有限数值；合成样本验证 v2 末尾边界不产生额外分段 | 子分段请求、插值、时间和坐标科学正确性 |

URI 检查只支持本地字面相对路径，拒绝远程、内嵌及越界路径；它是实验工具的输入限制，不是最终平台资源协议。

2026-10-28 复核：9 项自动测试通过，清单内 7 个真实文件通过；TypeScript strict 类型检查通过。新增测试遍历点数据、KTX2、DYN 合成样本的全部截断前缀，另查畸形 glTF，避免只验证正常输入。它们不能代替 `bash tools/check.sh --gpu`，也不能用来宣布第一版渲染完成。

## 回到整体规划

资源身份和部分布局已有可执行证据，但这还没有贯通任何用户场景。完整平台验收仍以 `docs/第一版规划与验收.md` 为准，不因本实验通过而勾选其中任何整项。

接下来先完成该文档的 B 阶段：围绕“总览—地球—月球—时间播放—返回”的候选流程，整理对象、时间、参考系、资源及相机协作契约和缺口，再安排 C 阶段的 Bevy/WASM 与 TS 插件贯通验证。模型加载、纹理转码、数据求值和交互都应服务这一流程，不能分别扩展成没有共同验收的子系统。

当前最关键的未验证项是：地月所需资源及时间覆盖是否齐全、DYN 求值与参考系是否正确、Bevy 浏览器端能否正确加载和显示、快速切换时是否清理旧请求与对象。Nyx、STK、市场与大模型自动化继续保留在后续阶段。
